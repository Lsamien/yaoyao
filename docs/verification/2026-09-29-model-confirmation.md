# 普通聊天模型切换确认与 Grok 4.7 验证

## 问题与修复

普通聊天把 `config.set` 返回的本地模型确认写入 `ChatRouteState.pendingApproval`。随后普通聊天 transcript 快照中的 `pendingApproval: null` 会清除此卡片，但待切换模型仍在本地保留。下一次发送再次要求确认，表现为模型名称已经改变、消息却发送失败。

模型确认现在单独保存为响应式状态，按会话显示，不再被服务端工具审批快照覆盖。确认后正常提交模型设置；取消或重新选择会清理旧确认，过期确认不会误发为工具审批。等待确认期间重复发送不重复请求模型切换。

## 验证

- 新增回归测试在修复前复现：模型确认经过 transcript 更新后变成 `undefined`。
- 修复后验证确认保留、确认后发送、无重复模型切换、重新选择清理旧确认，以及与工具审批互不覆盖。
- 65 项聊天、模型、同步和消息失败相关测试通过。
- `npm run typecheck` 与 `npm run build` 通过；构建仍有既有的大资源包提示。
