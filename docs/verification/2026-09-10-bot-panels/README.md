# Bot 模式机器人侧栏与 Grok Bot 云端电脑

## 完成内容

- 共享本地虚拟机按同一账号、同一执行节点绑定多个机器人，不再按基础 Profile 分成多台。虚拟机运行数量上限单独管理；独立模式仍保留。共享电脑保留已确定的工作目录，机器人保留独立会话。
- 机器人侧栏将电脑与定时任务作为居中的同组入口；Inspector 独立放在会话标题栏的聊天设置之后，标题栏与面板标题统一使用原侧栏的小虫图标。电脑选择参照 OpenMausBot：自动、Grok Bot 云端、本地虚拟机、本机、仅浏览器、不使用电脑。当前执行节点没有本机控制与独立浏览器连接，因此对应两项不可选。
- 自动选择保留可用本地虚拟机；新机器人可使用已就绪的本地执行节点，否则使用当前账号已连接的 Grok Bot 云端。查看侧栏只查询状态；显式打开云端电脑或实际工具执行才建立/唤醒连接。
- Grok Bot 使用服务端保存的加密凭据，按账号复用同一台虚拟机。机器人通过当前基础 Hermes 的工具桥获得云端 shell、文件读写、截图与桌面输入工具；云端地址和认证令牌不下发到浏览器或手机。
- 接管等待当前云端电脑操作完成，后续机器人电脑工具等待交还。两个页面不能同时取得控制；控制到期不自行恢复，重新接管并交还后才继续，交还说明进入后续工具结果。
- 群聊没有电脑查看或控制入口；任务选择器使用胶囊外观，并可从下拉末项直接新建、切换任务。聊天列表操作菜单可按类型“查看机器人”或“查看群聊”。
- 编辑机器人允许切换基础机器人，服务端校验来源授权、可用性和空闲状态。新执行使用新会话，近期聊天记录仍用于上下文。
- 定时任务支持单次、间隔、每日、每周和明确时区。任务、下次执行时间与执行记录持久化，重启后补执行一次到期任务，不集中重放漏掉的所有周期；相同任务未结束时跳过重叠执行。结果进入机器人原聊天。
- 定时任务排版对齐 OpenMausBot 的 RoutinesSection / RoutineList / RoutineLogs：顶部操作卡、独立任务卡、状态标记、下一次执行、最近结果、日志筛选与模态编辑器。仅编辑标题或提示词不会推迟原定执行时间。
- Inspector 排版对齐 OpenMausBot 的 InspectorPanel：Events / Raw 切换、条目计数、刷新图标、等宽紧凑行、方向/事件标签、连续 delta 合并与按需展开原始记录。
- Inspector 记录实际 Hermes 网关请求、响应、事件和错误，提供请求 ID、耗时与展开数据。每个聊天最多保留 2000 条，面板读取最新 400 条；凭据和附件数据隐藏，按账号/聊天/任务隔离，聊天删除时清理。
- 用户界面的 Agent 文案改为机器人；协议字段、代码标识与原有文件路径保持兼容。

## 验证

- 使用独立测试目录验证 Grok Bot 0.47.0 连接：状态读取成功，真实 shell 返回 Linux x86_64、box、/workspace，退出码 0；读取到 1280×800 PNG 桌面截图。未向真实云端发送桌面输入或改动工作文件。
- Web Playwright 使用一次性 Hermes fixture，覆盖编辑基础机器人、真实网关请求记录、独立 Inspector、居中的电脑/定时任务入口、定时任务创建/立即执行/完成、群聊任务新建与切换、多机器人列表滚动、群聊移除电脑入口，以及 375px 深色/减少动态效果显示。这里验证应用链路，fixture 回复不作为真实模型推理证据。
- 全量 Vitest：871 项通过、7 项按原配置跳过；生产构建通过。Web 完整侧栏流程 Playwright：1 项通过。iOS 本地签名模拟器：WorkspaceChatTests 33 项、界面测试 3 项通过。
- `desktop-computer.png`、`desktop-inspector.png`、`desktop-group-task-picker.png`、`desktop-agent-list-scroll.png`、`desktop-routines.png`、`phone-group-inspector.png` 均为本次 fixture 的实际浏览器截图。

## 启用

管理员在机器人电脑侧栏的「Grok Bot 云端连接」中使用服务器上已有的 Grok Bot 登录，或提交有效登录凭据；客户端版本默认为 0.47.0。选择云端需要基础机器人所在 Hermes 已启用 `yaoyao-bot-bridge`，远程执行节点需支持同一工具桥协议。

本次交付为 Web/桌面共用前端与服务端、iOS 源码和验证，不包含生产服务重启、桌面安装包发布或实体手机覆盖安装。
