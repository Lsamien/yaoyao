# 登录后的桌面运行模式切换

- 入口：登录后「我的设置 → 运行模式」，普通成员和管理员均可访问；原生菜单栏同时提供「运行模式」入口。
- 页面显示当前模式和服务器地址。选择客户端或服务器后点击切换；「更换服务器」打开原生登录窗口。
- 原生权限只允许当前服务的主窗口操作；普通浏览器隐藏此入口。切换保留独立服务和各服务器数据，成功后记住选择。

## 验证

- `npm run build` 与 `npm run typecheck` 通过。
- 设置组件 15 项测试通过，覆盖普通成员双向操作入口、浏览器隐藏、失败提示及更换服务器。
- `npm run desktop:test`：38 项通过。新增真实 Electron 验证双向切换、启动偏好、登录窗口复用和其他窗口的权限拒绝；补充验证远程登录窗口中返回服务器模式。
- 浏览器隔离预览使用模拟原生接口，验证了浅色、深色、375px 窄窗口和横屏布局，以及选择、切换与状态更新。未操作用户服务。
