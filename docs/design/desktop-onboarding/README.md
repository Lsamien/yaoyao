# 单页安装与登录

已确认的设计见 `approved-design.png`。桌面 App 的服务器选择、服务准备、创建管理员和登录在主窗口同一个 `boot.html` 页面中完成。

- 首次启动选择本机运行或远程连接；记住选择后再次启动自动检测。
- 本机复用服务管理器的环境检查、组件准备、服务启动流程。只有服务器要求初始化时才创建管理员；否则登录已有账号。
- 安装阶段显示后台实际步骤与消息，不显示未经测量的百分比。已完成的准备步骤收起为摘要，详情仍可在页内展开。
- 远程服务器检测成功后才接受账号密码。更改服务器地址会清空凭据并要求重新检测。
- 连接失败、登录失败、电脑授权失败均在页面内说明。账号登录成功但电脑授权失败时，可以继续进入工作区。
- 登录会话保留服务器提供的有效期和 SameSite 设置；“记住本次选择”保存服务器与运行方式，不保存密码。
- 设置中的模式切换、更换服务器、会话过期和重新授权复用主页面。原生登录弹窗及其四个资源文件已移除。

`preview-*.png` 由 Codex 内置浏览器打开实际页面样式与控制器、使用模拟服务后截图。`remote-*.png` 来自 Electron 集成测试；后者验证真实 IPC、HTTP 认证、Cookie 和窗口数量。

运行交互预览：

```sh
node scripts/preview-desktop-onboarding.mjs
```

打开 `http://127.0.0.1:4388`。预览会明确标注模拟服务，不会安装组件或连接输入的服务器。

验证覆盖首次启动、本机初始化、已有服务复用、错误重试、同版本覆盖恢复、远程登录、会话重启恢复、权限隔离、窗口内切换、服务崩溃恢复及后台生命周期。设计核对记录位于仓库根目录 `design-qa.md`。
