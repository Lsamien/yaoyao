### 交付边界

电脑采用容器级隔离，macOS 底层 Linux VM 由 Docker/Podman 提供；多桌面指多台独立电脑，共享电脑为单桌面串行，浏览器资料也共享。独立电脑各自保存浏览器资料。备份是确认停止后的文件一致备份，不是内存/应用事务快照。

Docker 已做真实运行验收；Podman 有接口与离线一致性测试，未做实机运行。远程节点使用相同的主动连接协议，Docker 控制面与容器外 Runner 已验收；没有宣称不同物理主机、全部操作系统版本均已实测。登录启动开关有实现和偏好验证，本轮没有重新登录 macOS。
