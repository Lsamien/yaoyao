# 聊天工作目录

夭夭 AI 与移动端通过同一个服务端执行规则，使用所选基础 Hermes Profile 的 `terminal.cwd`。客户端不决定服务器路径，也不把手机沙盒、Web 启动目录或历史会话目录作为覆盖值。

- 新建普通聊天和 Bot 模式聊天时，服务端读取该 Profile 的 `/api/config`，将 `terminal.cwd` 传给 Hermes。
- 旧会话恢复只恢复状态；在空闲会话下一次发送消息或上传附件前，使用 `session.cwd.set` 对齐工作目录。每次新一轮执行读取当前配置，目录已经一致时不重建终端。
- 正在执行、等待交互或接收排队消息的会话不在运行中切换目录。后续空闲发送再应用最新配置。
- 配置读取失败、路径无效或 Hermes 无法确认切换时，停止提交，不静默使用旧目录。旧版 Hermes 没有提供 `terminal.cwd` 时保留其默认行为。
- `.`、`~` 和相对路径交给实际执行的 Hermes 主机解析。需要固定目录时应在 Hermes 配置中填写该主机上的绝对路径。
- 扫码节点和远端 Agent 在目标服务读取自己的 Profile 配置，保留授权身份；原生 Hermes Bot 入口继续由其自身管理工作区。

这是夭夭 AI 服务端的规则，两端客户端无需额外获取或缓存工作路径。部署更新后的 Web 服务后，移动端通过该服务发送的下一轮消息即可使用此规则；不迁移历史文件，不修改 Hermes 全局配置。
