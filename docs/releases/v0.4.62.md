# 夭夭 AI v0.4.62

本次发布 Web、macOS Apple Silicon 桌面版和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 桌面端将服务器选择、环境检查、服务准备、创建管理员与登录整合到主窗口的同一个页面。安装阶段显示实际步骤，支持展开详情和失败重试。
- 远程连接先检测服务器，再填写账号；修改地址后清空旧凭据并重新检测。登录失败、会话过期和电脑授权失败均在页面内说明，模式切换与更换服务器复用此流程。
- “记住本次选择”保存服务器和运行方式，不保存密码；保留服务器设置的登录有效期，并修复恢复登录时的初始导航竞态。
- Web 与 macOS 登录页新增子账号注册。注册成功后等待管理员分配可用基础机器人并开通，不会自动登录或创建 Bot。
- 修复子账号 Bot 初始化快照被拦截的问题，补齐本人项目、记忆和协作入口；继续保留来源授权、跨账号隔离、撤权停止及管理员权限边界。
- 补充登录失效、权限撤回、来源不可用和离线恢复提示；保留合法 Bot 会话深链接，换账号时清理草稿与旧事件连接。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录。旧账号保留原启用状态、密码、来源分配及首次改密要求，不会自动获得额外授权。
- 请先更新服务端，再更新桌面客户端。注册仅作用于当前连接的服务器；管理员尚未初始化或服务器版本不支持时，不开放注册。
- 注册账号默认待开通；管理员需分配至少一个可用基础机器人后开通，普通“启用”操作不能绕过审核。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

```sh

docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.62`。镜像发布到 Docker Hub，GitHub 仅提供安装包、源码及校验文件。
