# 夭夭 AI v0.4.21 本地构建

本次生成 macOS Apple Silicon 桌面安装包，尚未发布到 GitHub 或 Docker Hub。

## 修复内容

- 取消“跳过原始记忆”和“跳过后台复盘”两个本机协作实验开关，恢复取消实验前的本机协作行为。
- 将修正版标为 v0.4.21，使 App 首次启动时能将仍运行实验功能的 v0.4.20 后台正常升级，避免回退源码后仍连接实验版界面。
- 升级沿用现有事务流程：服务空闲后备份数据并切换程序，保留聊天、设置和文件，失败时恢复。
- 保留 Bot 协作、三层文件记忆、技能共享及其他已完成功能。

## 安装与验证

安装后打开 App，等待本机 Web 同步完成。验收同时核对 App 与 15300 后台的版本、提交及服务包校验值，并从实际 v0.4.20 实验服务包验证升级和数据保留。服务忙碌时同步会延后，待任务完成后从夭夭菜单重试同步本机 Web。
