# v0.3.20

聊天模式与 Hermes 历史记录拆分为独立入口。

- `/chat` 只显示 `source=web`、由当前 8800 Web/iOS 创建的 Hermes Profile 会话，可新建并继续聊天。
- `/history` 只显示其他来源的 Hermes 会话，保留消息、文件和大纲浏览，不显示输入框，也不能继续或修改会话。
- 侧栏分别提供“聊天”和“历史记录”入口；历史页不会改变上次使用的聊天／Bot 模式。
- 服务端重新开放聊天 HTTP+SSE 通道，但在恢复会话前检查来源；历史会话不能借助直接链接恢复为可写会话。
- Bot 模式继续使用 8800 自有 Agent／群聊，不增加历史记录入口。
- Profile 名称和头像读取重新可用，不再回退为 `default` 和绿色默认头像。

配套 iOS 继续为 1.3（177）。
