# 夭夭 AI v0.4.15

本次发布 Web、macOS Apple Silicon 桌面版及 Docker Web 双架构镜像，附带正式签名的 Android 1.3（167）安装包。Android 本次无新增代码，沿用上一版已验证的安装包。

## 更新内容

- 本地虚拟机支持配置空闲自动停止时间，可选 1、5、10、15、30、60、120 分钟或“永不”，默认 5 分钟。设置保存在执行节点，适用于该节点管理的动态虚拟机。
- 任务执行或接管时取消空闲计时，归还后重新计时。选择“永不”仅关闭空闲自动停止，主动停止、取消、授权撤销、租约到期及执行节点退出仍会停止实例。
- Bot 的“使用本机”改为虚拟机下独立的可选开关，选择本地虚拟机或 Grok Bot 后才显示。切换到其他电脑环境会清除勾选，再切回虚拟机需要重新开启。
- 开启后，Bot 可在使用虚拟机的同时使用执行节点本机的已授权命令和文件工具，并通过 `computer_copy_file` 显式复制文件。单次文件上限 25 MiB，同名目标会覆盖。这里的本机是 Hermes 所在节点，不一定是打开网页的电脑。
- 虚拟机与本机之间保持明确的文件访问边界；任务或接管进行期间不能切换环境。新建 Bot 成员和临时助手不会自动继承本机访问权限。
- 旧版混合环境配置迁移为“本地虚拟机 + 使用本机”。已连接且获授权的 macOS 节点还可使用本机桌面工具；没有屏幕授权时仍可使用已授权的命令和文件工具。

## 升级说明

- 使用独立 Runner 的部署需要同步更新执行节点，才能使用空闲停止设置及本机工具能力（`host-computer-tools-v1`）。
- 固定 Compose 桌面的数量与启停仍由 Compose 管理，空闲自动停止设置不接管其生命周期。
- 数据目录继续使用 `.yaoyao`，沿用已有数据卷与密钥。升级前备份数据。
- 产品名称为“夭夭 AI”，主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.15-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.15` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 版本镜像验证后指向同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.15
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.15`。独立电脑镜像沿用现有版本，Cursor 继续使用 `samienluo/yaoyao-desktop:v0.4.12-cursor-amd`。保留旧版本标签与附件。Docker 镜像发布到 Docker Hub，GitHub 不上传镜像归档。

最终附件摘要、Docker manifest 摘要和运行验证记录发布在 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.15)。
