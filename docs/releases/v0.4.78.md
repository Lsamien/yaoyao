# 夭夭 AI v0.4.78

本次发布 Web、Docker 双架构镜像和 macOS Apple Silicon 纯客户端。full 桌面安装包不在本次发布范围；Windows 和 Android 沿用旧版附件。

## 更新内容

- 新增 Bot 密码管理界面，支持加密存储、手动解锁、短时任务授权、撤销、加密备份及主密码轮换。
- 增加受控网站表单、SSH 与 SFTP 凭据适配器；仅执行用户预先配置并授权的操作，返回脱敏结果，结果不明确时不自动重试。
- 新增统一未读中心，按聊天模式汇总未读消息，支持跳转与已读处理；macOS Dock 角标使用服务端确认的未读状态。
- 改善跨端已读回执与聊天同步，处理并发追加、部分提交及写入结果不明确的情况。
- 修复发送与排队时的聊天布局跳动，兼容不同聊天日期格式，减少流式输出时重复扫描未读历史。
- 修正上下文用量统计、上传文件名称与命令行安装行为。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新客户端。
- 独立部署的 Runner 应随服务端一起更新，以支持凭据引用及任务授权链路；客户端安装成功不代表服务端或 Runner 已更新。
- 密码库及受保护执行适配器默认关闭，需按仓库部署文档配置独立服务身份、私有 IPC 和人工确认的隔离条件。当前版本不自动安装密码库服务或更改系统权限；网站首期仅支持预先配置的标准 HTTPS 表单，复杂登录转人工接管。
- macOS 安装包为纯客户端，需要连接已有服务器，不包含本机服务器或执行节点运行时。需要桌面内置本机服务的用户可继续使用历史 full 包。
- macOS 客户端沿用历史应用标识，使用 Developer ID Application 正式签名和 Apple 公证，并提供完整自动更新附件。历史开发签名版请先手动安装正式 DMG。
- Windows 和 Android 旧版附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.78-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.78` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为本次双架构镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.78
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 镜像配置设为 `samienluo/yaoyao:v0.4.78`。Docker 镜像上传到 Docker Hub；GitHub 提供客户端、源码和校验附件。旧版本标签与附件保留。

附件摘要、镜像摘要和验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.78)。
