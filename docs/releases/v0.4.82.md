# 夭夭 AI v0.4.82

本次发布 Web 源码、Docker 双架构镜像和 macOS Apple Silicon 纯客户端。full、Windows 和 Android 沿用历史附件。

## 更新内容

- 设备授权限定为当前电脑客户端所在的本机，由本机原生窗口确认；不接收网页传入的目标设备编号，拒绝服务端下发的远程授权命令。
- 在「Bot 设置 → 环境与授权 → 设备授权」集中显示各设备的在线状态、屏幕控制、系统权限和文件与命令授权。
- 浏览器和手机 Web 可查看设备状态；其他设备仅显示状态，需要在对应电脑客户端上授权。
- 聊天电脑面板与独立电脑窗口仅提供本地虚拟机、云虚拟机和托管浏览器入口，真实电脑及服务器的授权状态集中到 Bot 设置。
- 授权确认期间若客户端连接已改变或用户取消，保持原有权限，不写入新的授权。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录；服务端、电脑客户端和独立执行节点应同步更新。
- 旧远程授权接口及旧服务端下发的授权命令会被拒绝。请先更新服务端，再在需要授权的电脑上安装新客户端，通过 Bot 设置授权本机。
- 屏幕控制与文件、命令权限独立。其他设备不能在当前电脑上代为授权；已授权设备的 Bot 工具能力保持独立。
- macOS 安装包为纯客户端，需要连接已有服务器，不包含本机服务器或执行节点运行时。历史 full、Windows 和 Android 附件保留。
- macOS 沿用历史应用标识，使用 Developer ID Application 正式签名和 Apple 公证，并提供完整自动更新附件。历史开发签名版请先手动安装正式 DMG。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

```sh
docker pull samienluo/yaoyao:v0.4.82

docker compose --env-file docker.env up -d --no-build web
```

Compose 镜像配置设为 `samienluo/yaoyao:v0.4.82`。镜像上传到 Docker Hub，GitHub 提供客户端、源码和校验附件。旧标签与旧附件保留。
