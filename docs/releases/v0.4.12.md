# 夭夭 AI v0.4.12

本次发布 Web、macOS Apple Silicon 桌面版、Docker Web 双架构镜像和 Cursor Universal 兼容桌面镜像。Android 沿用已签名且源码未变的 1.3（165）安装包。

## 更新内容

- 电脑环境可选择标准桌面或 Cursor Universal 桌面，各环境保留独立镜像选择、工作文件和浏览器资料；共享成员使用同一桌面的镜像。
- Docker Web 新增 `compose.desktops.cursor.yaml`，一次部署 Web 和一台 Cursor 开发桌面。镜像加入 CUA 驱动及私有 Unix socket 桥接层，固定已验证的上游 digest。
- Compose 继续管理固定桌面数量和生命周期，Agent 在电脑面板选择已有桌面。提供两种镜像混合部署和可选联网配置。
- 群聊可直接创建，按需启用交付目标；任务面板按运行情况展示状态，并补齐协调、调度与工具调用检查。
- 侧栏工具入口统一为交叉工具图标。

## 下载

- `Yaoyao-0.4.12-arm64.dmg`：macOS Apple Silicon，Apple Development 开发签名，未做 Apple 公证。
- `Yaoyao-1.3-165-android.apk`：Android 12 及以上，与 v0.4.11 的正式签名附件相同。
- `Yaoyao-0.4.12-source.tar.gz`：Web、桌面端源码及 Docker Compose 配置。

## Docker Hub 镜像

| 镜像 | 架构与用途 |
| --- | --- |
| `samienluo/yaoyao:v0.4.12-amd` | Web，`linux/amd64` |
| `samienluo/yaoyao:v0.4.12` | Web，`linux/amd64` / `linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后指向本次 Web 通用镜像 |
| `samienluo/yaoyao-desktop:v0.4.12-cursor-amd` | Cursor Universal 兼容桌面，`linux/amd64` |

Cursor 基础镜像为 `public.ecr.aws/k0i0n2g5/cursorenvironments/universal:sand-box-latest@sha256:858b6df5d0aeffd5db0e20c81553e98f84b07e9c700a13fcd1febac0e8c54830`。ARM64 宿主运行该桌面需要 amd64 模拟支持。

在源码包目录复制 `docker.env.example` 为 `docker.env`，配置可访问的 Hermes 9119 地址，并设置：

```dotenv
HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.12
YAOYAO_CURSOR_DESKTOP_IMAGE=samienluo/yaoyao-desktop:v0.4.12-cursor-amd
```

```sh
docker compose --env-file docker.env -f compose.desktops.cursor.yaml pull web desktop-cursor
docker compose --env-file docker.env -f compose.desktops.cursor.yaml up -d --no-build
```

默认桌面为 2 CPU、4 GB 内存、512 MB 共享内存，无外网且不发布桌面控制端口。工作文件与浏览器资料保存在命名卷。首次使用按 [Docker 部署说明](../docker-install.md#hermes-执行连接) 注册执行节点。

镜像 digest、远端架构、运行方式和发布附件核验结果记录在 [本版本 GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.12)。Web 固定标签验证通过后更新 `latest`，旧版本标签与附件保留。

## 升级

升级前备份数据目录和密钥；Docker 更新通过拉取镜像并重建容器完成，保留命名卷，不使用 `down --volumes`。已有固定桌面切换镜像时保留 ID、service 和数据卷，并先结束正在执行的任务。

本机 App 首次启动仍只同步较旧的本机 Web；默认数据目录为 `~/.yaoyao`。
