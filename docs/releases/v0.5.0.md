# 夭夭 AI v0.5.0

本次发布 Web 源码、Docker 双架构镜像、macOS Apple Silicon 纯客户端和 Android 正式安装包。

## 更新内容

- 服务端内置运行核心，简化部署与启动过程；管理员可在设置中管理模型服务、供应商、账号和密钥。
- Web 与移动端统一使用 Bot 模式，集中管理角色、群聊和相关工具。旧版普通聊天入口已移除。
- 改进旧会话迁移、电脑客户端局域网连接，以及执行节点配置。
- 优化模型准备、请求历史整理和回复进度显示。
- Android 客户端更新至 1.5.0 / 228，适配新服务端。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录、加密密钥和旧运行环境数据。首次启动后确认旧会话、模型配置及权限导入结果。
- 此版本调整了服务端协议和聊天入口，请同步升级 Android、iOS 和 macOS 客户端；旧客户端与新服务端不保证兼容。
- macOS 安装包为 Apple Silicon 纯客户端，需连接已有服务器。历史完整版及 Windows 安装包保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## 下载与镜像

- `Yaoyao-0.5.0-arm64.dmg`：macOS Apple Silicon 客户端。
- `Yaoyao-1.5.0-228-android.apk`：Android 正式签名安装包。
- ZIP、差分文件和 `latest-mac.yml` 供 macOS 自动更新使用；源码与校验文件另附。
- Docker Hub：`samienluo/yaoyao:v0.5.0` 支持 AMD64 和 ARM64；`v0.5.0-amd` 支持 AMD64；`latest` 指向本次通用镜像。

GitHub 发布页：[夭夭 AI v0.5.0](https://github.com/Lsamien/yaoyao/releases/tag/v0.5.0)。
