# 夭夭 AI v0.4.9

本次发布 Web、macOS Apple Silicon 桌面版和 Android 1.3（164），包含此前尚未正式发布的 v0.4.8 改动。

## 更新内容

- 修复普通聊天用户消息重复回显，统一发送回执、实时事件与历史记录的消息身份；保留连续发送相同文字的独立消息。
- 修复工具调用重复累计及结束后仍显示运行中的问题。进度通知与真实调用分开处理，真实调用按 ID 合并；失败和未确认结果保留准确状态。
- 改进历史与实时消息合并，保护仍在执行的回合和排队输入，避免迟到历史覆盖当前对话。
- 新增服务端“文件访问”设置，由管理员配置额外允许目录或全局授权；当前 Profile 的实际工作目录始终允许，Web 与移动端统一走服务端权限校验。
- 服务器文件预览统一携带 Profile。预览失败显示文件名、具体原因与重试入口；上传和归档附件保留原有权限规则。
- 修复服务器图片切换新文件接口后无法打开大图的问题，保持图库顺序、文件名及重试后的预览关联。
- 安卓同步修复工具状态、历史合并和服务器文件预览。

## 升级与文件权限

官方发布地址为 https://github.com/Lsamien/yaoyao/releases/tag/v0.4.9 。App 首次启动继续只同步较旧的本机 Web，保留已有更新的独立 Web；默认数据目录为 `~/.yaoyao`。

文件访问默认只允许当前 Profile 工作目录及其子目录，管理员可在“设置 → 文件访问”中添加目录或开启全局授权。规则在服务器即时生效，仍受 Hermes 自身认证、敏感文件与宿主权限限制。配置随服务端数据目录备份，详见 [服务端文件访问权限](https://github.com/Lsamien/yaoyao/blob/v0.4.9/docs/file-access.md)。

升级前备份完整数据目录及加密密钥。源码或 Docker 部署更新版本后重新构建并重启服务，保留原数据目录或命名卷。
