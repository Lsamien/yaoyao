# 夭夭 AI v0.4.68

本次发布 Web、macOS Apple Silicon 桌面版和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 修复 Docker 目录映射模式下工具桥安装失败：使用容器内的 Python 安装共享数据目录中的插件，避免错误调用当前容器中不存在的上游运行环境。
- 映射模式下仅安装工具桥，明确提示 Profile 模型兼容修复需在上游服务所在容器或节点单独执行；本机安装仍保留原有兼容修复流程。
- 完善映射安装的成功与失败提示，以及共享目录权限、默认 Profile 安装顺序和服务重启的部署说明。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录和共享的上游配置目录。更新容器后，在服务管理页面重新检查并安装工具桥。
- 先安装默认 Profile 的工具桥，再安装其他 Profile；完成后在空闲时重启上游服务。映射模式不会自动重启其他容器或修改其运行环境。
- 桌面采用开发签名 DMG 手动安装，未做 Apple 公证。本次不提供自动升级 ZIP、差分文件或更新清单。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## 下载

- `Yaoyao-0.4.68-arm64.dmg`：macOS Apple Silicon，开发签名，未公证，手动安装。
- `Yaoyao-0.4.68-source.tar.gz`：Web/桌面源码及部署配置。
- `SHA256SUMS.txt`：上述附件的 SHA-256 校验值。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.68-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.68` | `linux/amd64`、`linux/arm64` |

```sh
docker pull samienluo/yaoyao:v0.4.68
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.68`。镜像发布到 Docker Hub，GitHub 仅提供安装包、源码及校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.68)。
