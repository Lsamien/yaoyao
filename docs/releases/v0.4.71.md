# 夭夭 AI v0.4.71

本次发布 Web、macOS Apple Silicon 正式桌面版、Windows x64 未签名测试客户端和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 改善断网、页面切回前台和服务器短暂不可达后的自动恢复，重新同步会话、运行状态与待审批内容，避免重复发送消息。
- 修复实时事件重连后的补发与游标处理，检测遗漏消息并恢复完整记录，避免界面停留在过期状态。
- 改善工具授权续期和上游连接恢复：临时网络故障在原授权有效期内重试，明确失效或撤销的授权仍会终止。
- 新增 Windows 10/11 x64 客户端，可连接已有夭夭服务器，支持聊天、电脑授权、主屏截图与键鼠控制、独立浏览器，以及授权后的文件和命令操作。
- 完善跨平台设备识别、路径边界、命令取消与子进程清理，以及登录、托盘、退出和更新行为。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新桌面客户端。
- macOS 桌面使用 Developer ID Application 正式分发签名及 Apple 公证，提供完整自动更新附件；已安装正式签名版的用户可使用“下载更新 → 重启更新”，历史开发签名版请先手动安装正式 DMG。
- Windows 为未签名测试客户端，可能提示未知发布者；安装到当前用户目录，连接已有服务器，不托管本机服务。Windows 电脑操作需要本次配套服务端支持。
- Windows 测试更新清单随独立元数据压缩包提供，不写入正式自动更新源。Windows Server CI 验证结果与尚未完成的 Windows 10/11 真机项目分别列出，详见 [客户端说明](../windows-client.md)。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

- `Yaoyao-0.4.71-arm64.zip`、DMG 与 ZIP 对应的 `.blockmap`、`latest-mac.yml`：macOS 自动更新载荷与清单。
- `Yaoyao-0.4.71-win-x64-setup.exe`：Windows x64 未签名测试安装包。
- `Yaoyao-0.4.71-windows-test-metadata.zip`：Windows 测试更新清单、差分文件、构建身份、说明及校验值；解压后与安装包放在同一目录使用。
- `Yaoyao-0.4.71-source.tar.gz`：Web/桌面源码及部署配置。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.71-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.71` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.71
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.71`。镜像发布到 Docker Hub，GitHub 提供安装及更新附件、源码和校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.71)。
