# 夭夭 AI v0.4.67

本次发布 Web、macOS Apple Silicon 桌面版和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 改进 Bot 的 MCP 与应用工具发现：按服务或关键词筛选工具，支持分页，一次返回有效工具 ID 和完整参数，减少重复搜索和读取整个工具目录。
- 在每轮对话中提供实际已连接的服务清单，明确工具在服务器运行，区分工具可用、连接失败和账号未登录等状态。
- 修复 MCP 服务的 Bot 授权管理，支持单独调整授权对象；Bot 列表读取失败时显示明确状态，避免误清空授权或选择无效 Bot。
- 优化记忆增量和会话复用：新增记忆按需补入原会话；已用记忆被修改、删除，授权范围变化或提交结果不确定时，重新建立会话，避免继续使用失效事实。
- 修正普通 Bot 对话被误当作看板任务的引导，避免没有真实任务 ID 时反复调用看板工具。
- 完善服务端管理服务的重启功能：支持应用托管服务，并在 macOS 上核对系统服务与实际监听进程后重启；有运行任务时阻止重启，完成后检查连接与工具桥状态。远程或无法识别的服务显示具体原因。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新桌面客户端。
- 工具发现优化需要配套工具桥；升级后在服务管理页面检查并更新工具桥，按页面提示在空闲时重启服务。
- 旧会话首次迁移可能因缺少记忆基线而重新建立，聊天历史与持久记忆保留。
- 桌面采用开发签名 DMG 手动安装，未做 Apple 公证。本次不提供自动升级 ZIP、差分文件或更新清单。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。
