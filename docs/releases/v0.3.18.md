# v0.3.18

账号头像与新建 Agent 的默认头像规则在 Web 和 iOS 对齐。

- 登录账号默认显示用户名首字母；可在 Web 的“登录与安全”上传图片或恢复首字母，iOS 读取同一账号头像并显示，但不提供修改入口。
- 账号头像保存在 8800 用户资料中，沿用登录鉴权、CSRF、图片类型和大小限制，不影响密码及 Agent 身份。
- 新建 Agent 未主动选择头像时，由创建流程生成并保存随机 v2 内置头像；颜色、形状／造型和基础表情均参与随机。
- Web、iOS 创建界面进入时即可看到本次随机结果；服务端同时兜底处理未携带头像的客户端请求。

配套 iOS 为 1.3（177）。
