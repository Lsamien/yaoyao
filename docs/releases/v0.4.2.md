# v0.4.2

本次同时发布 Web 与 macOS Apple Silicon（arm64）桌面版，接入 GitHub 稳定版本升级。

- Web 默认从官方 GitHub Release 检查稳定版本，解析标签提交并核对发布清单；官方旧发布源自动迁移，自定义源保留原有 Git 标签流程。
- 桌面新增“检查 App 更新…”窗口，可独立检查版本、下载 DMG、取消或重试，并在大小、SHA-256 和 DMG 完整性校验后打开安装包，由用户手动安装。
- Web 检查及升级不依赖 9119；桌面检查不依赖 Web 在线。下载不会停止聊天、Runner 或独立后台服务。
- 网络失败、限流、清单错误和校验失败明确显示，不误报为最新版。更新窗口支持深浅色和键盘操作，原生接口拒绝其他页面调用。
- Docker 运行镜像包含发布源配置模块，继续由部署者重建镜像升级。

## 安装与升级

附件提供 `Yaoyao-0.4.2-arm64.dmg` 和 `SHA256SUMS.txt`。将“夭夭”拖入“应用程序”后打开。桌面包使用 Apple Development 开发签名，未公证，仅适用于 macOS Apple Silicon。

**旧版桌面需先手动安装一次 v0.4.2**，之后可使用“检查 App 更新…”。尚未包含迁移逻辑的旧程序不会自动切换发布源；也可更新源码后重新构建并重启。升级前备份完整 Web 数据目录。

App 首次启动仍只向上同步较旧的本机 Web，已有较新的服务保留。Docker 查看版本和发布页后由部署者重建容器。

详情见 [GitHub 版本升级](../github-updates.md)、[macOS App](../macos-app.md) 和 [Docker 部署](../docker-install.md)。
