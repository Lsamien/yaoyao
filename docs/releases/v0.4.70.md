# 夭夭 AI v0.4.70

本次发布 Web、macOS Apple Silicon 桌面版和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 修复桌面端检测服务器成功后仍无法登录的问题：注册、登录和电脑授权统一使用与连接检测相同的网络通道，保持登录会话独立，避免携带或覆盖其他账号的浏览器登录状态。
- 修复已停用的电脑仍出现在 Bot 设备清单中的问题；停用记录不会被残留连接或消息来源重新加入清单。
- 修复聊天中的 MEDIA 图片引用和归档附件重复展示，正确关联正文图片与保存后的附件地址。
- 在聊天电脑面板补齐共享桌面选择和连接入口，显示已连接、不可用等状态；连接失败时保留错误提示，避免被状态刷新清除。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新桌面客户端。
- 已安装正式签名版的用户可使用“下载更新 → 重启更新”；历史开发签名版请先手动安装正式 DMG。
- 桌面使用 Developer ID Application 正式分发签名及 Apple 公证，提供完整自动更新附件。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## 下载

- `Yaoyao-0.4.70-arm64.dmg`：macOS Apple Silicon 首次安装或手动更新。
- `Yaoyao-0.4.70-arm64.zip`、DMG 与 ZIP 对应的 `.blockmap`、`latest-mac.yml`：桌面自动更新载荷与清单。
- `Yaoyao-0.4.70-source.tar.gz`：Web/桌面源码及部署配置。
- `SHA256SUMS.txt`：所有发布附件的 SHA-256 校验值。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.70-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.70` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.70
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.70`。镜像发布到 Docker Hub，GitHub 提供桌面安装及更新包、源码和校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.70)。
