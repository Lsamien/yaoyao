# v0.3.28

- 子账号仅可使用 Bot 模式。管理员在创建账号或修改权限时分配基础 Agent，子账号只能基于获分配的本机 Profile 创建自己的 Bot Agent。
- 服务端拒绝子账号访问原生聊天、历史、实时通道、Hermes Bot 中继、节点管理、全局设置和原生媒体路径；账号自己的聊天、任务、文件、事件继续按 owner 隔离。
- 修改分配后旧会话失效，并请求停止已有任务；创建、发送、执行和审批阶段重新检查来源权限。升级前的子账号默认没有基础 Agent 分配，管理员需手动授权。
- Bot 模式支持通过配对子节点引用远程 Agent，配置由远端管理；节点地址修改验证身份，支持重新扫码续期。
- 原生 Hermes Bot 通过专用中继使用本机或配对子节点，保留与 Bot 模式工作区的独立边界。
- 配套 iOS 强制子账号进入 Bot 模式，并按服务端能力隐藏远程管理入口。

配套 iOS 1.3（188）。已有账号和聊天数据保留。应用账号授权不替代 Hermes 工具执行环境的权限约束，详见 [子账号权限](../subaccount-permissions.md)。
