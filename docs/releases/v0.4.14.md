# 夭夭 AI v0.4.14

本次发布 Web、macOS Apple Silicon 桌面版、iOS 1.3（200）、Android 1.3（167）及 Docker Web 双架构镜像。

## 更新内容

- Bot 会话列表跨端统一为“置顶优先 → 最新消息时间倒序 → ID 兜底”，首次加载、重连快照、实时更新和刷新使用同一规则。
- iOS 列表时间统一读取会话最新消息时间。Web、iOS、Android 在刷新期间收到新事件后，会丢弃旧列表响应，避免覆盖刚同步的置顶状态。
- iOS Bot 恢复过程摘要时间线抽屉，思考入口放到正文前，群聊机器人名称置于气泡外，并统一回复文字与段落排版。
- iOS 增加 OpenMausBot 同款三点输入动画，等待首字时显示，正文或思考出现、任务结束或停止后收起。
- iOS 补回正文 Markdown 图片、文件引用和原生附件预览；图片按原比例完整缩放，文件名独立显示，修复宽图撑宽会话、后续用户消息出框的问题。
- iOS 的 Markdown 文稿代码块默认格式化预览，可切换源码并复制原文；保留其他语言代码块的源码显示。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.14-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.14` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 版本镜像验证后指向同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.14
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.14`。独立电脑镜像沿用现有版本，Cursor 继续使用 `samienluo/yaoyao-desktop:v0.4.12-cursor-amd`。保留已有数据卷、旧标签和旧发布附件。

升级前备份数据与密钥。最终附件摘要、Docker manifest 摘要和运行验证记录发布在 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.14)。模拟器验证不等同于真机帧率测试。
