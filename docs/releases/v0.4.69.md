# 夭夭 AI v0.4.69

本次发布 Web、macOS Apple Silicon 桌面版和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 修复 Bot 模型设置在多 Profile 环境下无法加载模型列表或解析配置的问题。模型选择与解析同时使用当前 Profile 的配置和凭据作用域。
- 保持并发请求、嵌套调用和异常退出时的 Profile 凭据隔离，并兼容旧版服务的配置作用域入口。
- 桌面发布改用 Developer ID Application 正式分发签名及 Apple 公证，提供 DMG、自动更新 ZIP、差分文件和更新清单。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录和上游配置目录。升级服务端后，在服务管理页面更新工具桥，并在空闲时重启对应服务，让模型设置修复生效。
- 历史开发签名桌面版本请先手动下载安装本次正式签名 DMG；后续正式签名版本可使用“下载更新 → 重启更新”。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## 下载

- `Yaoyao-0.4.69-arm64.dmg`：macOS Apple Silicon 首次安装及旧版手动迁移。
- `Yaoyao-0.4.69-arm64.zip`、对应 `.blockmap` 和 `latest-mac.yml`：桌面自动更新载荷与清单。
- `Yaoyao-0.4.69-source.tar.gz`：Web/桌面源码及部署配置。
- `SHA256SUMS.txt`：所有发布附件的 SHA-256 校验值。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.69-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.69` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.69
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.69`。镜像发布到 Docker Hub，GitHub 提供桌面安装及更新包、源码和校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.69)。
