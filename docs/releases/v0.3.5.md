# v0.3.5

修复连接中断后执行状态长期停留在“待确认”、默认头像在单聊与群聊中不一致，以及中文句中的 @ 提及未触发回复的问题。

- 对待确认的执行自动重连并核对原会话历史；不会重复提交提示词，也不会将后续请求的回复当成本轮结果。
- 上游明确拒绝提交时显示执行失败并解除会话占用，保留异常原因以便定位。
- 同一个 Agent 的默认头像按 Agent ID 统一生成，单聊列表、会话标题与群成员组合保持一致；已设置的头像继续使用原值。
- 用户和 Agent 都支持在中文句中直接 @ 成员，例如“请@瑶儿继续”；按最长成员名称匹配，排除邮件、链接、代码和引用中的提及。
- 保持原有聊天页面布局，群成员仍然固定。

配套 iOS 1.3（170）。本版本更新 Web 服务。

## 验证

- 发布清单、类型检查与生产构建通过；85 个测试文件、465 项 Web 测试通过。
- 断线恢复不重复提交、延迟历史核对、后续回复隔离和明确拒绝的回归测试通过。
- 浏览器流程通过：不同成员的群头像与单聊头像一致，并实际触发中文句中 @ 指定成员回复。
