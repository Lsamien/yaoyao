# 夭夭 AI v0.4.5

本次更新 Web 与 macOS Apple Silicon 桌面版，同时附带 Android 1.3（162）正式签名 APK；安卓源码与 v0.4.4 所附版本相同。

- 普通聊天列表、正文分页、置顶和未读从 Web 本地数据库读取，已保存的内容无需等待 Hermes 历史请求。
- 实时事件与消息在同一事务内保存，再通过 SSE 推送；改进重复事件识别、消息身份与发送状态，避免刷新后消息重复或丢失。
- 修复跨端会话自动标题的后台更新，已完整保存的正文不会因元数据变化而重复下载，本地手动标题继续保留。
- 缺失历史由独立的持久化队列补齐，支持并发限制、失败退避和重启恢复；后台补齐保留本地标题、置顶、已读状态与未确认发送。
- 修复 Docker 构建上下文，确保开放许可证与第三方署名文件完整进入镜像。

## 下载

- `Yaoyao-0.4.5-arm64.dmg`：macOS Apple Silicon，Apple Development 开发签名，未做 Apple 公证。
- `Yaoyao-1.3-162-android.apk`：Android 12 及以上，沿用正式发布密钥；与上一版本附件一致。
- `Yaoyao-0.4.5-source.tar.gz`：Web 与桌面端源码。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验文件。

## 升级

官方版本检查和下载地址为 https://github.com/Lsamien/yaoyao 。Web 与桌面版默认数据目录为 `~/.yaoyao`，继续兼容迁移旧目录。App 首次启动只同步较旧的本机 Web，保留已有更新的独立 Web。

本版增量更新聊天缓存表结构。升级前备份完整数据目录；若数据库结构已变化，回滚入口不会直接降级覆盖新数据。Docker 部署重新构建镜像并启动容器，保留原命名卷。
