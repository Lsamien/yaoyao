# 夭夭 AI v0.4.61

本次发布 Web、macOS Apple Silicon 桌面版和 Docker 双架构镜像，不提供 APK。此版本汇总 v0.4.22 之后的本地更新，并包含最新头像刷新修复。

## 更新内容

- 修复刷新页面时短暂出现绿色默认头像的问题。头像资料尚未加载或图片失效时显示中性占位，保留用户设置的照片与造型。
- 完善 Bot 资料、结构化角色偏好、独立模型设置与分层记忆；修复冷恢复后模型设置失效、记忆提炼空结果和记忆检索问题，并显示保存结果。
- 完善多台电脑及虚拟环境管理，支持桌面端切换客户端与服务器模式、远程登录、逐台授权、电脑改名和重新授权。
- 电脑接管页面支持切换预览环境，减少轮询造成的闪跳。完善共享桌面的执行调度、多环境操作、文件与命令授权及跨设备文件复制。
- 修复 Bot 会话同步、普通聊天排队与停止状态、节点失联时的任务退出，以及工具分段完成后输入动画提前消失或持续残留的问题。
- 消息正文、图片和文件按原顺序独立展示；统一文件卡片识别及传输上限，提供聊天气泡预设与自定义外观。
- 统一任务进度、审批、提问与错误提示，默认折叠交付进展，默认隐藏思考过程和工具细节，减少重复技术报错。
- 修复文件路径权限边界，并在归档或删除 Bot 时清理相关电脑共享关系。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录。保留旧数据目录迁移兼容逻辑，不改变现有数据归属。
- 建议同步更新桌面端与配套执行节点，并检查工具桥实际加载状态及电脑授权状态。
- 本次不构建、不上传 APK；旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.61-amd` | `linux/amd64` |

```sh
docker pull samienluo/yaoyao:v0.4.61
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.61`。镜像发布到 Docker Hub，GitHub 仅提供安装包、源码及校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.61)。
