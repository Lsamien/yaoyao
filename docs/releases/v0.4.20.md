# 夭夭 AI v0.4.20

本次发布 Web、macOS Apple Silicon 桌面版及 Docker Web 双架构镜像。Android APK 按要求不重新打包，附带上一版已验证的 1.3（171）安装包。

## 更新内容

- Bot 支持异步联系同伴：请求立即返回投递凭据，同伴完成后继续原会话或话题。界面可查看协作状态、请求与结果，并停止整条协作链；迟到结果不会重新启动已停止的工作。
- 新建群默认平等讨论，无需先选负责人；未点名时全员参与，逐轮轮换发言顺序。支持 1–12 轮、最多 8 位成员，单个成员失败不阻止其他成员。已有群保留原协作模式，需要交付时可继续使用目标与验收流程。
- 新增独立项目，可关联多个群，单聊也可选择当前项目。项目成员关系单独管理，群内成员需先加入项目才能使用项目记忆。
- 新增 Bot、用户、项目三层文件记忆。共享事实按贡献 Bot 分开保存，保留来源、更新时间与修订记录，支持搜索、人工编辑、遗忘和 Markdown 导出。
- Bot 资料提供协作和自动记录开关，默认开启。暂停自动记录保留已有记忆；用户编辑受保护，遗忘与修订保留屏障，防止旧提炼任务重新写回旧事实。
- 记忆提炼在后台执行，失败可查看和重试，不阻塞聊天。协作链有投递次数、深度和重复内容限制，异步结果返回原话题后再合并提炼。

## 升级与兼容

- 本次新增项目、记忆和协作管理界面交付于 Web/macOS。复用的 Android 1.3（171）未包含 Android 新源码中的对应管理界面。
- 完整记忆能力需要更新配套执行节点，并由节点声明隔离记忆和无工具提炼能力；不支持时界面提示升级。共享基础配置不会被改写。
- 文件记忆和项目保存在 `.yaoyao/bot-workspace/<账号 ID>/`。升级前使用一致性快照，或停服后备份整个数据目录，包含数据库、WAL、附件及 `bot-workspace`。
- 普通聊天继续使用 v2 协议，服务端和客户端仍需配套升级。独立电脑的数量、数据卷和生命周期沿用已有部署配置。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.20-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.20` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 版本镜像验证后指向同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.20
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.20`。旧版本标签与附件保留。Docker 镜像发布到 Docker Hub，GitHub 不上传镜像归档。

最终附件摘要、镜像摘要和运行验证记录发布在 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.20)。
