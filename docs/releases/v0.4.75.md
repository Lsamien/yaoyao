# 夭夭 AI v0.4.75

本次发布 Web、macOS Apple Silicon 正式桌面版、Windows x64 未签名测试客户端、Android 正式签名 APK 和 Docker 双架构镜像。

## 更新内容

- 桌面首次使用改为分步选择运行方式、连接服务器和登录，优化紧凑窗口与深色模式。
- 持久化桌面登录授权，完善服务重启、模式切换后的会话恢复，以及主动退出后的授权清理。
- 修复重复设备注册造成的重复通知，保持不同设备的未读角标互不干扰。
- 修复人工拖动请求字段，确保浏览器接管时拖动坐标和协议匹配。
- Android 更新聊天流式缓存、多端通知处理和托管浏览器卡片，优化消息间距、日期与到底部按钮，并修复文件预览关闭后的交互问题。

## 升级说明

- 默认执行位置与允许使用的环境分别配置；托管浏览器的配套 Chromium 首次使用时下载。浏览器和虚拟机保持独立的登录资料。
- 请同时更新服务端、执行节点与桌面镜像中的工具桥接程序；使用虚拟机全局代理时同步更新 Compose 配置并构建配套网络网关镜像。更新前请结束正在运行的任务。
- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新桌面客户端。
- macOS 桌面使用 Developer ID Application 正式分发签名及 Apple 公证，提供完整自动更新附件；已安装正式签名版的用户可使用“下载更新 → 重启更新”，历史开发签名版请先手动安装正式 DMG。
- Windows 为未签名测试客户端，可能提示未知发布者；安装到当前用户目录，连接已有服务器，不托管本机服务。
- Windows 测试更新清单随独立元数据压缩包提供，不写入正式自动更新源。Windows Server CI 验证结果与尚未完成的 Windows 10/11 真机项目分别列出，详见 [客户端说明](https://github.com/Lsamien/yaoyao/blob/v0.4.75/docs/windows-client.md)。
- Android APK 为 1.5.0（226），沿用正式发布签名。安装前建议备份数据；旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.75-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.75` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.75
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.75`。镜像发布到 Docker Hub，GitHub 提供安装及更新附件、源码和校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.75)。
