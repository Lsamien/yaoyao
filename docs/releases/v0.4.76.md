# 夭夭 AI v0.4.76

本次发布 Web、Docker 双架构镜像和 macOS Apple Silicon 客户端桌面版。本次未发布完整版桌面安装包（内嵌本机服务器的「夭夭完整版」沿用 v0.4.75）；Windows 与 Android 客户端沿用旧版附件。

## 更新内容

- 统一普通聊天图片上传与历史显示路径，历史消息中的图片显示更稳定。
- 补充子账号机器人创建成员的权限回归测试，收紧相关权限行为。
- 修复纯客户端包的原生助手签名校验与加密报错，本机服务器相关报错信息更明确。
- 准备 npm 发布：`@lsamien/yaoyao` 包名与发布字段就绪，服务端可通过 npm 安装。
- 桌面客户端沿用历史 App 标识，完整版改用独立身份；从旧版「夭夭」升级安装时原地替换、保留登录与配置，本次同步完善安装说明。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录；建议先更新服务端，再更新桌面客户端。
- macOS 桌面客户端使用 Developer ID Application 正式分发签名及 Apple 公证，提供完整自动更新附件；已安装正式签名版的用户可使用“下载更新 → 重启更新”，历史开发签名版请先手动安装正式 DMG。
- 「夭夭完整版」本次未发布新安装包，v0.4.75 完整版仍可连接 v0.4.76 服务器使用；需要完整版新功能的用户请等待后续版本。
- Windows 与 Android 客户端沿用各自旧版附件，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## 下载

- `Yaoyao-0.4.76-arm64.dmg`：macOS Apple Silicon 客户端首次安装或手动更新。
- `Yaoyao-0.4.76-arm64.zip`、DMG 与 ZIP 对应的 `.blockmap`、`latest-mac.yml`：macOS 客户端自动更新载荷与清单。
- `Yaoyao-0.4.76-source.tar.gz`：Web/桌面源码及部署配置。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.76-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.76` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.76
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.76`。镜像发布到 Docker Hub，GitHub 提供安装及更新附件、源码和校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.76)。
