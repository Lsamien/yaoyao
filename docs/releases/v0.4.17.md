# 夭夭 AI v0.4.17

本次发布 Web、macOS Apple Silicon 桌面版、Android 1.3（169）及 Docker Web 双架构镜像。

## 更新内容

- Bot 消息被服务器接收后立即恢复发送状态，后台同步不再阻塞输入。重试沿用原请求编号，旧回执不会清除新草稿或覆盖更新的会话状态。
- 优化流式消息传输：首段及时显示，后续文本以更细的间隔合并更新，长回复使用持久化增量补丁，减少重复传输完整消息的流量。
- 完善断线、刷新及历史恢复。补丁缺失或顺序不连续时重新同步，保留已加载历史；修复长回复跟随与异步排版后的定位，用户上翻阅读时保持当前位置。
- 同一 Bot 可在不同会话或话题中同时回复，各自保留独立的上下文、消息、审批和停止操作。同一会话的追问继续排队并复用原会话。
- Bot 全局最多同时执行 10 个轮次，超出的已接收工作继续排队。同一群聊最多接收 10 个未完成话题，超过时明确提示；单个话题仍最多并行 3 个成员轮次。
- 并发额度与虚拟机数量独立，共享电脑和浏览器仍遵循各自的操作队列与独占规则。
- 完善桌面升级验证，正式版使用高于上一正式版及本轮测试版的版本号，保留已有服务设置与数据。
- Android 1.3（169）同步更新发送确认、流式补丁、长回复跟随与历史恢复。

## 升级说明

- 旧客户端继续兼容完整消息传输，新客户端按服务器能力启用增量消息。
- 本版事件日志包含新的流式格式。升级前备份 `.yaoyao` 数据与密钥；需要关闭增量协议时使用本版后端的兼容模式，避免直接换回不能识别新日志格式的旧后端。
- 桌面和执行节点建议同步更新至配套版本。固定桌面的数量与生命周期沿用已有部署配置。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

```sh
docker pull samienluo/yaoyao:v0.4.17
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.17`。独立电脑镜像沿用现有配置，保留旧版本标签与附件。Docker 镜像发布到 Docker Hub，GitHub 不上传镜像归档。
