# 夭夭 AI v0.4.18

本次发布 Web、macOS Apple Silicon 桌面版、Android 1.3（170）及 Docker Web 双架构镜像。

## 更新内容

- 修复普通聊天后台历史补齐后，切回会话仍显示旧内容的问题。历史请求、分页与流式更新交错时，保留当前回复和已加载的旧消息，避免迟到响应覆盖新状态。
- 修复桌面长期打开后安全令牌过期导致发送消息或保存设置失败的问题。明确收到令牌失效拒绝时自动续领并重试一次，同窗口请求合并续领，多窗口协调签发；取消、超时或切换账号后不重放旧操作。
- 账号菜单新增“检测更新”。桌面版可直接打开原生更新窗口，网页版管理员可查看当前版本、最新版本及更新说明，并进入更新设置。重复点击复用已有更新窗口。
- 精简 Bot 模式的账号与设置入口，减少重复按钮，并完善桌面和窄屏菜单的键盘操作与焦点恢复。
- 增加普通聊天统一消息记录、可重放事件流和恢复检查点的试验实现。Android 1.3（170）加入对应能力识别与本地检查点存储，默认继续使用现有同步协议。

## 升级说明

- 普通聊天新同步协议默认关闭，仅设置 `HERMES_YAOYAO_ORDINARY_TRANSCRIPTS=1` 后启用。该试验功能尚未完成全部跨端联调、特殊过程事件与断线分页边界验收，本次稳定使用路径保持原有协议。
- Android 本地数据库增加恢复检查点表，沿用正式发布密钥，可覆盖升级已有安装。
- 数据目录继续使用 `.yaoyao`。升级前备份数据与密钥，保留已有数据卷、执行节点及独立电脑配置。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

```sh
docker pull samienluo/yaoyao:v0.4.18
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.18`。独立电脑镜像沿用现有配置，保留旧版本标签与附件。Docker 镜像发布到 Docker Hub，GitHub 不上传镜像归档。
