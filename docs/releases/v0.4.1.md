# v0.4.1

本次同时更新 Web 与 macOS Apple Silicon（arm64）桌面版。

- 修复 Docker 镜像构建和执行节点接入，支持由 Compose 预先创建、数量固定的共享桌面，补充部署配置与生成工具。
- 更新本地虚拟机图标，将聊天内电脑选择改为标签切换，保留键盘导航与控制权约束。
- 精简聊天顶部操作，支持从搜索列表删除已归档 Bot 和群聊。
- 修复聊天文件的来源归属，文件展示聚焦用户附件与实际交付产物，排除执行过程文件。

## 安装与升级

GitHub 发布附件提供 `Yaoyao-0.4.1-arm64.dmg` 和 `SHA256SUMS.txt`。桌面包使用 Apple Development 开发签名，未做 Apple 公证；适用于 macOS Apple Silicon。

App 首次启动会按既有规则同步较旧的本机 Web，保留较新的服务及原有配置。Hermes 基础运行时需独立配置；本地虚拟机另需 Docker 或 Podman。Docker Compose 固定共享桌面配置见 [Docker 部署说明](../docker-install.md)。

Web 可通过既有系统升级入口更新；源码部署切换到 `v0.4.1` 后重新构建并重启，Docker 部署重新构建镜像。升级前备份完整 Web 数据目录。详情见 [macOS App](../macos-app.md) 和 [本地虚拟机](../local-vm.md)。
