# 夭夭 AI v0.4.16

本次发布 Web、macOS Apple Silicon 桌面版、Android 1.3（168）及 Docker Web 双架构镜像。

## 更新内容

- 本地 Worker 在创建或恢复会话时继承基础 Profile 的自动压缩开关、阈值、消息保留规则、重试与超时设置，以及模型上下文长度和最大输出配置；人工接管后继续当前轮次沿用原配置快照，下一轮读取新配置。
- 压缩完成、工具执行进度及轮次结束时保存历史，失败返回的压缩历史也会保留；旧 Worker 的迟到检查点不能覆盖新状态。压缩后继续使用当前轮次已授权的虚拟机工具。
- 上下文已满且压缩关闭，或压缩耗尽重试／超时时，本轮显示具体失败原因，持久虚拟机释放控制权进入空闲，按已有空闲策略停止。“永不自动停止”仍然有效。取消、授权失效、执行状态不确定、异常退出及未分类失败继续停止旧运行实例。
- Web Inspector 修复最新记录排序与顶部定位，打开、切换视图及在顶部刷新时优先显示最新记录，查看旧记录时保留阅读位置。
- Android 新增 Inspector，可查看倒序 Events / Raw，流式片段合并后保持组内正文正序；新增虚拟机“允许本机环境”开关，支持保存与重新进入后恢复，并遵循服务端授权及任务状态限制。
- 补充夭夭与 OpenMausBot 的移动端收发延迟模拟器对比记录，记录测试条件、请求链与测量边界。

## 升级说明

- 独立部署 Runner 的用户需同步更新配套执行节点，才能使用本次 Worker 压缩与错误恢复修复。Grok Bot 云端会话路径继续沿用现有实现。
- 固定 Compose 桌面的数量与启停仍由 Compose 管理，动态本地虚拟机沿用已有空闲策略。
- 数据目录继续使用 `.yaoyao`，保留已有数据卷与密钥；升级前备份数据。主项目许可为 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| --- | --- |
| `samienluo/yaoyao:v0.4.16-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.16` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 版本镜像验证后指向同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.16
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.16`。独立电脑镜像沿用现有版本，Cursor 继续使用 `samienluo/yaoyao-desktop:v0.4.12-cursor-amd`。保留旧版本标签与附件。Docker 镜像发布到 Docker Hub，GitHub 不上传镜像归档。

最终附件摘要、Docker manifest 摘要和运行验证记录发布在 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.16)。
