# 夭夭 AI v0.5.1

- 新增独立管理后台。升级后，用户继续从原 Web 地址聊天，管理员在服务器本机打开 `http://127.0.0.1:15301`，使用管理员账号重新登录。
- 用户管理、模型服务、执行节点与系统更新等设置迁入后台。后台支持验证器二次验证、敏感操作密码确认与审计日志。
- Docker Compose 增加管理端口映射，并保留默认工作目录中的文件。远程管理及自定义监听地址参见[管理后台文档](../admin-console.md)。

## 下载与更新

[GitHub Release](https://github.com/Lsamien/yaoyao/releases/tag/v0.5.1) 提供源码、Apple Silicon 客户端 DMG、自动更新 ZIP 与差分文件，以及 Android 1.5.0（229）正式安装包。Android 在连接新版服务端时会从管理员设置引导至独立后台。

Docker 用户可设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.5.1` 并按仓库 Compose 配置拉取、重新创建容器。通用标签 `v0.5.1` 和 `latest` 支持 AMD64 与 ARM64，`v0.5.1-amd` 供 AMD64 使用。升级前备份应用数据卷。
