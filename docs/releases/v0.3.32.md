# v0.3.32

- 统一 Web 和移动端聊天的工作目录，使用所选基础 Hermes Profile 的 `terminal.cwd`，包括普通对话、Bot 单聊和群聊。
- 新会话创建时传入配置目录；旧会话在下一次空闲发送或上传附件前纠正目录，不再优先沿用历史路径。
- 配置变更在后续空闲执行时生效。正在执行的回复不切换目录；目录已一致时不重建终端。
- 配置读取失败或 Hermes 无法切换到该目录时停止提交，避免静默在错误目录执行。远端 Agent 使用目标服务自己的配置和授权身份。

本次修复由 Web 服务端统一执行。升级 Web 后，已有移动端即可使用同一规则，无需迁移历史文件或修改全局配置。原生 Hermes Bot 入口仍使用其自身工作区管理。

`terminal.cwd` 的 `.`、`~` 和相对路径由实际执行的 Hermes 主机解析；需要固定目录时请填写该主机上的绝对路径。详见[聊天工作目录规则](../chat-working-directory.md)。
