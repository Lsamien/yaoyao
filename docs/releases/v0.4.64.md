# 夭夭 AI v0.4.64

本次发布范围为 Web、macOS Apple Silicon 桌面版及 Docker 双架构镜像，不提供 APK。

## 更新内容

- 统一 Bot 的设备环境快照，使提示词、工具列表和环境检查页面使用同一份设备状态。区分设备在线状态、授权、文件访问、命令执行、屏幕查看与控制能力，避免将不可用设备或能力误报为可用。
- 按任务、设备环境、应用和记忆组织 Bot 上下文，明确服务端与所选电脑的作用、实际工作目录及文件传输限制。桌面与服务器协商环境信息上报能力，并保留旧客户端兼容处理。
- 接入桌面自动升级流程，补齐检查、下载、取消、系统准备及重启安装状态；失败时保留可操作提示，避免下载完成但系统尚未准备好时提前安装。
- 修复远程客户端的更新入口，检查当前桌面应用版本；更新窗口可独立于本机 Web 服务使用。
- 修复恢复已登录会话时短暂显示登录引导页的问题。
- 调整桌面聊天附件样式，缩小附件展示并取消文件名加粗。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录。建议先更新服务端，再更新桌面客户端。
- 设备能力仍受账号授权、连接状态及全局设置约束；升级不会自动授予新的电脑访问权限。
- 桌面自动升级需要同一正式分发签名身份及 Apple 公证；既有手动安装版需先手动安装正式包。具体签名、公证状态及自动升级可用范围以本次 GitHub 发布页的实际验证结果为准。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## 下载

- `Yaoyao-0.4.64-arm64.dmg`：macOS Apple Silicon 桌面安装包。
- `Yaoyao-0.4.64-source.tar.gz`：Web/桌面源码及部署配置。
- `SHA256SUMS.txt`：本次实际发布附件的 SHA-256 校验值。
- 桌面自动升级所需 ZIP、差分文件和更新清单，仅在正式签名、公证及安装验证完成后提供。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.64-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.64` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.64
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.64`。镜像发布到 Docker Hub，GitHub 仅提供安装包、源码及校验文件。

附件签名、摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.64)。
