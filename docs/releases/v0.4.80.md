# 夭夭 AI v0.4.80

本次发布 Web、Docker 双架构镜像和 macOS Apple Silicon 纯客户端。full 桌面安装包不在本次发布范围；Windows 和 Android 沿用旧版附件。

## 更新内容

- 将未读入口调整为顶部铃铛，重新设计消息面板，改善跳转、标记已读及跨端计数更新。
- 默认提供本机密码保险箱，可通过密码管理界面创建主密码、手动解锁并保存加密条目，无需预先配置独立密码库服务。
- 明确本机保险箱与独立执行服务的能力边界；显式配置的独立服务连接失败时保留离线状态。
- 修复普通聊天删除失败，增加取消和失败重试确认，避免重复删除请求。
- 扩展服务端本机执行服务重启的识别与归属核验，兼容自定义服务和受支持的终端启动方式。
- 修复 MCP 与应用板块的供应商标识显示，保留第三方图标许可与署名。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新客户端。
- 独立部署的 Runner 建议随服务端一起更新；客户端安装成功不代表服务端或 Runner 已更新。
- 本机密码保险箱默认锁定，数据加密保存在 `.yaoyao/credential-vault/`，只提供凭据存储与手动管理，不签发 Bot 任务授权或执行自动登录。
- 本机保险箱使用服务端进程，不具备独立 OS 身份隔离保证。真实凭据的自动使用仍需按部署文档配置并验收独立密码库服务；已配置服务不可用时不会切换到本机保险箱。
- macOS 安装包为纯客户端，需要连接已有服务器，不包含本机服务器或执行节点运行时。需要桌面内置本机服务的用户可继续使用历史 full 包。
- macOS 客户端沿用历史应用标识，使用 Developer ID Application 正式签名和 Apple 公证，并提供完整自动更新附件。历史开发签名版请先手动安装正式 DMG。
- Windows 和 Android 旧版附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.80-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.80` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为本次双架构镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.80
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 镜像配置设为 `samienluo/yaoyao:v0.4.80`。Docker 镜像上传到 Docker Hub；GitHub 提供客户端、源码和校验附件。旧版本标签与附件保留。

附件摘要、镜像摘要和验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.80)。
