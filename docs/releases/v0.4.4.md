# 夭夭 AI v0.4.4

本次发布 Web、macOS Apple Silicon 桌面版和 Android 1.3（162）正式签名 APK。

- Bot 模式桌面接管参考 OpenMausBot，打开独立的大画面窗口；支持直接键鼠操作、适应窗口、原始大小、全屏和收起的键盘面板，关闭窗口前交还控制权。
- Web 默认数据目录改为 `~/.yaoyao`。旧版 `~/.hermes-yaoyao` 整体迁移，保留账号、会话、文件、加密密钥和执行节点状态，并迁移内部文件索引。默认新旧目录同时有数据时保留两份数据并提示处理，不自动覆盖。
- 统一版本检查、版本比较、安装包下载与源码入口为 https://github.com/Lsamien/yaoyao 。旧官方地址自动归一化，自定义仓库保留。
- 产品介绍统一为“夭夭 AI”，采用 Apache-2.0 开源许可证，保留第三方许可与署名。

## 下载

- `Yaoyao-0.4.4-arm64.dmg`：macOS Apple Silicon。使用 Apple Development 开发签名，未做 Apple 公证。
- `Yaoyao-1.3-162-android.apk`：Android 12 及以上，使用本次新建的正式发布密钥签名。若设备上已有使用其他签名的开发版，不能直接覆盖安装。
- `Yaoyao-0.4.4-source.tar.gz`：Web 与桌面端源码。
- `SHA256SUMS.txt`：以上附件的 SHA-256 校验。

## 升级与迁移

App 首次启动等待本机服务空闲，迁移数据并同步较旧的 Web；较新的独立 Web 继续保留。Web 仍可独立升级。旧升级器的事务先在原目录完成，之后由新版本迁移助手等待空闲并重启至新目录。

支持 `YAOYAO_HOME`，兼容既有 `HERMES_YAOYAO_HOME`。显式自定义目录保持不变。原有 LaunchAgent 标识、程序发布目录、浏览器缓存键和账号身份命名空间保留兼容，避免丢失已有安装或重置身份；实际默认应用数据写入 `~/.yaoyao`。

Docker 继续使用原 Compose 项目和 `yaoyao-data` 命名卷，容器内数据目录改为 `/home/node/.yaoyao`。重新构建并启动 Compose 即可复用原卷。不要执行删除数据卷的操作。

迁移后本地虚拟机按新目录重新挂载持久工作区和浏览器资料。原来的已停止容器保留为带 `before-data-move` 后缀的备份，未自动删除其可写层。
