# 夭夭 AI v0.4.19

本次发布 Web、macOS Apple Silicon 桌面版、Android 1.3（171）及 Docker Web 双架构镜像。

## 更新内容

- 普通聊天正式使用服务端统一消息协议 v2。流式输出、历史恢复和上游消息编号变化时保持稳定的显示身份，明确区分输入、回合、正文片段与工具调用，减少重复消息和内容覆盖。
- 消息、事件收据与重放日志在同一事务中保存。断线后从已保存位置继续，发现事件缺口或会话代次变化时重新同步；分页不会覆盖更新的消息或恢复已经删除的记录，保存失败不推进恢复位置。
- 修复普通聊天发送前本地缓存写入失败，以及刷新后未恢复运行和待处理交互状态的问题。缓存保存独立快照，恢复检查点时同步还原界面状态。
- 已有普通聊天记录通过后台队列核验，运行中的会话延后处理。切换前保留历史、消息及关联记录的存档；无法确认归属的已接收输入保留并等待核验，不按文本相同删除消息。
- 本地虚拟机新增“本机协作模式”，在已有本机会话和授权工具的基础上加入虚拟机操作，支持显式复制文件与回传产物。旧记录仍使用原虚拟机模式，任务或人工接管期间不能切换，临时助手和新成员不自动继承该模式。
- 修复执行节点协作模式能力握手被过滤的问题，配套节点可正确显示和启用本机协作能力。
- 桌面启动页和应用菜单新增“使用当前 App 覆盖同版本 Web”。需要用户主动选择，执行前校验完整性、归属与空闲状态并备份，失败时恢复；忙碌时延后，不中断当前任务。
- Android 1.3（171）同步接入普通聊天 v2，持久保存消息与恢复检查点，并保留待确认输入。

## 升级要求

**普通聊天存在协议兼容性变更，请将服务端和客户端配套升级。**

- Web/macOS 使用 v0.4.19，Android 使用 1.3（171）。其他移动端也必须具备 v2 支持；旧客户端普通聊天会收到升级提示，新客户端不再回退到旧消息协议。升级服务端前请确认所使用的客户端均已支持 v2。
- v2 是正式代码路径，v1 试验开关不再控制普通聊天。Bot 模式及原生机器人通道保持各自原有协议边界。
- 升级前备份 `.yaoyao` 数据与密钥。旧数据核验将在新服务启动后后台执行；需要回退时使用配套备份恢复流程，避免直接让旧程序读取升级后的数据。
- 本机协作模式需要更新配套执行节点，并在基础会话中启用所需工具桥。固定桌面的数量和生命周期继续由原部署配置管理。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

```sh
docker pull samienluo/yaoyao:v0.4.19
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.19`。独立电脑镜像沿用现有配置，保留旧版本标签与附件。Docker 镜像发布到 Docker Hub，GitHub 不上传镜像归档。

最终附件摘要、镜像摘要和运行验证记录发布在 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.19)。模拟器和协议测试不能替代实体设备后台挂起及蜂窝/Wi-Fi 切换验收，这些真机场景尚未完成验证。
