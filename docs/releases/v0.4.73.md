# 夭夭 AI v0.4.73

本次发布 Web、macOS Apple Silicon 正式桌面版、Windows x64 未签名测试客户端和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 新增托管浏览器，与现有虚拟机共用节点鉴权和任务通道；支持网页操作、截图、文件上传下载及与虚拟机交换文件。
- 浏览器环境首次使用时按需安装，显示准备与下载状态；旧节点配置自动检测，失败后可重试。
- 聊天中提供浏览器状态卡片，支持在 Web 电脑面板和桌面独立窗口接管，并与当前任务使用同一页面。
- 按账号和 Bot 隔离浏览器会话与登录资料；任务结束后保留页面，空闲后自动回收，支持下一轮继续使用。
- 完善人工接管、交还、取消和断线后的权限隔离，避免共享虚拟机中取消一个任务影响其他任务。
- 修复虚拟机工具连接恢复和桌面就绪等待，隔离插件连接故障；补齐桌面浏览器依赖并增加签名前的实际包内容验收。

## 升级说明

- 托管浏览器工具默认关闭，由管理员启用；配套 Chromium 首次使用时下载。浏览器和虚拟机保持独立的登录资料。
- 请同时更新服务端与执行节点；Compose 虚拟机需结束运行任务后同步更新桌面镜像中的桥接程序，以使用新的取消协议。
- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新桌面客户端。
- macOS 桌面使用 Developer ID Application 正式分发签名及 Apple 公证，提供完整自动更新附件；已安装正式签名版的用户可使用“下载更新 → 重启更新”，历史开发签名版请先手动安装正式 DMG。
- Windows 为未签名测试客户端，可能提示未知发布者；安装到当前用户目录，连接已有服务器，不托管本机服务。
- Windows 测试更新清单随独立元数据压缩包提供，不写入正式自动更新源。Windows Server CI 验证结果与尚未完成的 Windows 10/11 真机项目分别列出，详见 [客户端说明](https://github.com/Lsamien/yaoyao/blob/v0.4.73/docs/windows-client.md)。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.73-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.73` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.73
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.73`。镜像发布到 Docker Hub，GitHub 提供安装及更新附件、源码和校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.73)。
