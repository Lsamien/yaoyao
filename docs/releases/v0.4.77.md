# 夭夭 AI v0.4.77

本次发布 Web、Docker 双架构镜像和 macOS Apple Silicon 纯客户端。full 桌面安装包不在本次发布范围；Windows 和 Android 沿用旧版附件。

## 更新内容

- 修复 Bot 删除失败后的重试和原执行停止确认，减少残留任务与生命周期状态不一致的问题。
- 修复拆分部署时 Bot 对服务端执行环境的识别。
- 修复实时命令过期去重与持久回执恢复，提升断线恢复后的状态一致性。
- 修复归档文件授权，并在登出后关闭 Bot 事件连接。
- 改善记忆合成的账号调度，限制并行读取，避免部分账号长期得不到处理。
- 修复桌面开发启动时纯客户端与完整版的模式及应用身份选择。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新客户端。
- macOS 安装包为纯客户端，需要连接已有服务器，不包含本机服务器或执行节点运行时。需要桌面内置本机服务的用户可继续使用历史 full 包。
- macOS 客户端沿用历史应用标识，使用 Developer ID Application 正式签名和 Apple 公证，并提供完整自动更新附件。历史开发签名版请先手动安装正式 DMG。
- Windows 和 Android 旧版附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## 下载

- `Yaoyao-0.4.77-arm64.dmg`：macOS Apple Silicon 纯客户端安装包。
- `Yaoyao-0.4.77-arm64.zip`、两种安装包对应的 `.blockmap` 和 `latest-mac.yml`：自动更新附件。
- `Yaoyao-0.4.77-source.tar.gz`：Web/桌面源码和部署配置。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验值。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.77-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.77` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为本次双架构镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.77
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 镜像配置设为 `samienluo/yaoyao:v0.4.77`。Docker 镜像上传到 Docker Hub；GitHub 提供客户端、源码和校验附件。旧版本标签与附件保留。

附件摘要、镜像摘要和验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.77)。
