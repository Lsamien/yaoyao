# v0.3.4

恢复原有聊天界面组件，修复 v0.3.0 新建 Agent 无法发送、单聊置顶失败，以及头像配置与运行状态显示的问题。

- 修复局域网 HTTP 下请求编号生成失败，新建 Agent 可以连续收发并恢复历史。
- 聊天复用原有消息时间线、输入框与侧栏，移除额外的协作状态栏。
- 群聊头像由真实成员动态组合；执行与等待状态联动当前成员头像，单个 Agent 在列表中也同步显示状态。
- 列表显示最后消息时间，空聊天显示创建时间；置顶、改名和修改资料不会改变最后消息时间。
- 修复单聊置顶被默认头像字段误判为编辑资料，以及修改规则时清空头像的问题。
- 头像支持圆形、椭圆、圆角方形、胶囊、小三角、六边形、云朵和水滴，提供 14 种颜色、随机外形、重置与图片上传。
- 扩展头像在 iOS、Web 和群聊组合中同步保存、渲染；会话名称旁不再显示额外的 Agent 字样。

固定群成员、独立角色规则、Web 服务所有权保持不变。

配套 iOS 1.3（169）。

## 验证

- 版本清单、类型检查与生产构建通过。
- 85 个测试文件、460 项单元与服务测试通过。
- 当前聊天浏览器端到端流程通过：局域网请求编号降级、创建角色、连续协作、固定群成员、单聊置顶、跨页面历史同步、文件来源及归档恢复。
