# v0.4.0

本次同时发布 Web 与 macOS Apple Silicon（arm64）桌面版。

- 新增“夭夭”macOS App，内置 Web、Node 运行时和 Runner；首次启动同步较旧的本机服务，支持后台运行、完整停止、登录启动设置及加密保存执行节点配置。
- Bot 可在用户授权后组建成员与团队，创建有负责人、依赖和验收条件的任务；临时助手有独立标识及退役清理。
- 新增本地虚拟机准备与维护、聊天内电脑面板、人工接管及交还控制；支持显式授权的跨成员共享电脑和持久工作目录。
- 完善 Runner、隔离 Hermes Worker、受控网络访问、任务产物回传，以及归档 Bot、群聊和不存在会话的删除与清理。
- 保留手动会话管理，撤回 v0.3.33 的自动清理行为。

## 安装与升级

桌面安装包：`Yaoyao-0.4.0-arm64.dmg`，附 SHA-256 校验文件。将 App 拖到“应用程序”后打开；本机服务同步规则见 [App 与 Web 版本同步](../app-web-sync.md)。

DMG 使用 Apple Development 开发签名，未做 Apple 公证。此包适用于 macOS Apple Silicon；本次不提供 Intel、Windows 或 Linux 桌面安装包。Hermes 基础运行时仍需独立配置，本地虚拟机另需 Docker 或 Podman。

Web 可通过既有系统升级入口更新；源码部署切换至 `v0.4.0` 后重新构建并重启，Docker 部署重新构建镜像。升级前备份整个 Web 数据目录。更多说明见 [macOS App](../macos-app.md)、[本地虚拟机](../local-vm.md) 和 [桌面生命周期](../desktop-lifecycle.md)。
