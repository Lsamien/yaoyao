# 夭夭 AI v0.4.81

本次发布 Web 源码、Docker 双架构镜像和 macOS Apple Silicon 纯客户端。full、Windows 和 Android 沿用历史附件。

## 更新内容

- 桌面更新入口放到顶部铃铛旁，仅在有更新时显示；下载进度、准备状态和重启按钮直接呈现在当前页面，无需打开独立更新窗口。启动及登录页面也可使用更新入口。
- macOS npm 服务端支持先下载并校验更新，由管理员点击「重启服务器」后就地覆盖安装；关闭或重新打开页面不会自动重启，下载状态保留。
- npm 覆盖更新复用当前安装路径，清理临时安装包和旧程序文件，不保留额外版本副本或回滚备份，用户数据保持原位。
- 支持为指定 Bot 持续授权使用凭据，管理界面锁定与已授权 Bot 使用独立；修复修改凭据后授权失效的问题，并简化保存和授权流程。
- 获得 SSH 凭据授权的 Bot 可执行远端命令并读取输出；支持撤销授权、主机密钥固定、输出限制及操作审计。
- 缩减聊天启动数据，大段工具结果按需加载，改善聊天切换和长会话显示性能。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新客户端；独立部署的执行节点也应同步更新。
- npm 界面升级适用于 macOS LaunchAgent 服务，使用 npm 发布源检查更新；GitHub Release 和 Docker 标签发布不等同于 npm 仓库已经发布。下载完成后仍需管理员手动点击重启；覆盖或启动失败需要修复当前安装，不会自动恢复旧程序。
- 本机密码保险箱在服务端进程内执行已授权操作，不具备独立 OS 身份隔离保证。管理界面锁定不会撤销已授予 Bot 的持续授权，停止使用请明确撤销；重启后管理界面仍需解锁。
- SSH 持续授权允许 Bot 在对应主机上执行任意远程命令。只为可信 Bot 授权，检查主机和账户权限。首次连接固定主机密钥，后续变化需人工确认。
- 显式配置的独立密码库服务连接失败时保持离线，不会自动切换到本机保险箱。
- macOS 安装包为纯客户端，需要连接已有服务器，不包含本机服务器或执行节点运行时。历史 full 包继续保留。
- macOS 沿用历史应用标识，使用 Developer ID Application 正式签名和 Apple 公证，提供完整自动更新附件。历史开发签名版请先手动安装正式 DMG。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

| --- | --- |
| `samienluo/yaoyao:v0.4.81-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.81` | `linux/amd64`、`linux/arm64` |

```sh
docker pull samienluo/yaoyao:v0.4.81
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 镜像配置设为 `samienluo/yaoyao:v0.4.81`。Docker 镜像上传到 Docker Hub；GitHub 提供客户端、源码和校验附件。旧版本标签与附件保留。

附件摘要、镜像摘要和验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.81)。
