# 夭夭 AI v0.4.22

本次发布 Web、macOS Apple Silicon 桌面版及 Docker Web 双架构镜像，不提供 APK。v0.4.21 为此前的本地构建，正式版本提升到 v0.4.22，便于已有安装正常升级。

## 更新内容

- 独立 Bot 设置，集中管理项目、用户记忆和本地虚拟机；“我的设置”保留账号资料、安全、外观、连接及系统管理。统一弹窗、分类导航、主题预览和窄屏布局。
- 统一虚拟机 Bot 的基础会话、模型、视觉路由、技能与授权管理，保留虚拟机模式和本机协作模式各自的执行边界。
- 新增工具桥插件的检查、安装、启用、更新与重新安装入口。区分已安装版本和实际加载版本，显示未启用、需更新、待加载和已就绪等状态，并保留安装备份与失败恢复。
- 桌面安装包和执行节点安装包补齐工具桥、安装器及技能相关资源。Docker 镜像提供安装器依赖，并支持可选目录映射配置。
- Bot 可在回合结束后独立复盘并沉淀可复用技能，继续保留记忆隔离；关闭基础会话的原始记忆和上下文文件自动加载，避免自动混入 Bot 上下文。
- 修复会话创建的记忆参数兼容问题，以及刷新期间用量更新与检查点保存交错导致运行状态、待审批提示未恢复的问题。

## 升级说明

- 建议同步更新配套执行节点，并在“我的设置 → 连接”中检查工具桥。插件写入完成后，根据界面提示使目标服务加载新版本；“已安装”不等于“已加载”。
- Docker 可按部署文档使用 `compose.hermes-bridge.yaml` 映射目标配置目录，目录需允许容器用户写入。仅在已配置的映射范围内执行安装。
- 升级前备份整个 `.yaoyao` 数据目录，包括数据库、附件、项目与文件记忆。普通聊天继续使用 v2 协议，客户端需保持配套版本。
- 本次不构建、不上传 APK，已有 Android 发布附件保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.22-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.22` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后指向同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.22
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.22`。旧版本标签和附件保留，镜像发布到 Docker Hub，GitHub 不上传镜像归档。

附件摘要、镜像摘要和验证记录见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.22)。
