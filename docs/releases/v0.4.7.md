# 夭夭 AI v0.4.7

本次更新 Web、macOS Apple Silicon 桌面版和 Android 1.3（163）。

## 更新内容

- 普通聊天的未读数只统计最终助手回复，不再把用户消息、思考过程或中间片段计入；Web 与 Android 统一采用最终回复未读数，并兼容旧服务返回值。
- Bot 模式“已连接应用”改为独立大面板，汇总应用目录、连接账号和 MCP；自动化改为独立日程页，支持 Bot 筛选、日历、任务编辑与运行日志。
- “关于”使用独立对话框，可从常规工作区底部菜单直接打开；上述功能不再混入设置中心。
- macOS 应用图标使用纯白圆角底板，修复透明背景显示问题；保留原有机器人头像与个性化配置。

## 下载

- `Yaoyao-0.4.7-arm64.dmg`：macOS Apple Silicon，Apple Development 开发签名，未做 Apple 公证。
- `Yaoyao-1.3-163-android.apk`：Android 12 及以上，包含未读数修复，沿用原正式发布密钥。
- `Yaoyao-0.4.7-source.tar.gz`：Web 与桌面端源码。
- `SHA256SUMS.txt`：发布附件的 SHA-256 校验文件。

## 升级

官方发布地址为 https://github.com/Lsamien/yaoyao/releases/tag/v0.4.7 。App 首次启动继续只同步较旧的本机 Web，保留已有更新的独立 Web；数据目录仍为 `~/.yaoyao`。

升级前备份完整数据目录及加密密钥。源码或 Docker 部署更新版本后重新构建并重启服务，保留原数据目录或命名卷。
