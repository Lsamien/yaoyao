# 夭夭 AI v0.5.2

管理后台现在使用管理员账号和密码直接登录。升级后，原先启用的验证器二次验证也会停止生效，包括允许远程访问的部署。默认后台地址仍为服务器本机的 `http://127.0.0.1:15301`。

- 管理员在后台「我的账号」修改用户名。Web 和移动端移除了剩余的管理入口，手机扫码登录对所有账号开放。
- macOS 客户端登录后直接进入工作区。要将本机注册为可远程控制的电脑，请在后台生成配对码，再从客户端「电脑」菜单输入。
- 提供 Web 源码、macOS Apple Silicon 客户端及自动更新文件、Android 1.5.0（230）正式安装包和 SHA-256 校验文件。[下载附件](https://github.com/Lsamien/yaoyao/releases/tag/v0.5.2)
- Docker 通用镜像 `samienluo/yaoyao:v0.5.2` 和 `latest` 支持 AMD64 与 ARM64。`v0.5.2-amd` 供 AMD64 使用。升级前备份数据卷，按现有 Compose 配置拉取镜像并重新创建容器。
