# v0.3.27

- 普通聊天归属改由 Web 服务持久化的“用户 + Agent + canonical Session ID”登记决定；`source` 只保留来源元数据，不再参与列表、续聊或修改权限。
- Web 和 iOS 统一使用 `/api/app/sessions` 权威投影；跨端新建、标题生成和 `sessions.changed` 会实时刷新另一端，无需重载页面。
- 修复 iOS 未识别 Hermes 实际 `session.title` 事件、新建失败后留下本地幽灵会话、未读辅助路径错误，以及重启后误入上次会话。
- 服务端自行补齐 `order=recent` 与 `archived=exclude`，避免旧调用方因缺参将上游错误暴露为 HTTP 500。
- 旧 v0.3.26 registry 仅在本地用户和缓存 owner 都唯一且一致时做一次性接管；多用户、配对设备、搜索、分页、置顶和标题竞态都按新的 owner registry 隔离。

配套 iOS 1.3（184）。
