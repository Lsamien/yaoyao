# v0.3.31

- 采用 LaoA 双眼头像与基础轮廓，移除额外嘴巴和外围留白。列表圆形头像可见尺寸约放大 20%，异形头像保持比例，文字位置和行距不变。
- 统一维护可生成的头像数据，包含 8 个基础形状、10 个额外造型和 25 套双眼表情；保留现有颜色、上传照片、裁剪与 v2 头像配置。
- 新增服务器统一名称：在“设置 → 登录与安全”修改，同一服务器上的 Agent 共用，Web、iOS、安卓读取同一配置。管理员可修改，普通账号只读；留空恢复服务端主机名。
- 名称修改校验版本和目标服务器，防止旧编辑页或并发保存覆盖其他端的修改。通过现有事件通道及登录、前台恢复等必要时机同步。

升级继续使用原数据目录。服务器名称保存在现有 SQLite 数据库的独立表中，不改动 Agent 名称、连接地址、账号或会话记录。升级前建议备份 Web 数据目录。

本次发布 Web。手机端的完整新头像样式及服务器名称编辑需要包含对应更新的 iOS/安卓客户端；本次不附带 IPA 或 APK。
