# 夭夭 AI v0.4.74

本次发布 Web、macOS Apple Silicon 正式桌面版、Windows x64 未签名测试客户端和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 修复上游认证异常、迟到请求和桌面 Cookie 合并造成的反复登录及登录状态提前失效。
- 统一运行环境与系统服务授权，分别设置默认执行位置和允许使用的环境；支持弹窗浏览器完成账号授权，并保留文件导入方式。
- 支持在 Bot 对话中创建属于当前 Bot 的定时任务，完善任务归属与权限检查。
- 增加虚拟机全局代理与独立网络网关，准确报告代理就绪失败，避免失败时绕过代理直连。
- 正常完成任务后按空闲策略保留虚拟机；服务启动时恢复已配置的本机虚拟机。
- 重建虚拟机时保存并迁移用户授权资料，先正常关闭桌面应用以写入最新凭据，并在迁移前核对网络身份。
- 完善托管浏览器拖拽操作和人工连续拖动，支持拖动取消与接管交还。

## 升级说明

- 默认执行位置与允许使用的环境分别配置；托管浏览器的配套 Chromium 首次使用时下载。浏览器和虚拟机保持独立的登录资料。
- 请同时更新服务端、执行节点与桌面镜像中的工具桥接程序；使用虚拟机全局代理时同步更新 Compose 配置并构建配套网络网关镜像。更新前请结束正在运行的任务。
- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新桌面客户端。
- macOS 桌面使用 Developer ID Application 正式分发签名及 Apple 公证，提供完整自动更新附件；已安装正式签名版的用户可使用“下载更新 → 重启更新”，历史开发签名版请先手动安装正式 DMG。
- Windows 为未签名测试客户端，可能提示未知发布者；安装到当前用户目录，连接已有服务器，不托管本机服务。
- Windows 测试更新清单随独立元数据压缩包提供，不写入正式自动更新源。Windows Server CI 验证结果与尚未完成的 Windows 10/11 真机项目分别列出，详见 [客户端说明](https://github.com/Lsamien/yaoyao/blob/v0.4.74/docs/windows-client.md)。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

| --- | --- |
| `samienluo/yaoyao:v0.4.74-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.74` | `linux/amd64`、`linux/arm64` |

```sh
docker pull samienluo/yaoyao:v0.4.74
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.74`。镜像发布到 Docker Hub，GitHub 提供安装及更新附件、源码和校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.74)。
