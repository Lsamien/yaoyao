# 夭夭 AI v0.4.13

本次发布 Web、macOS Apple Silicon 桌面版、iOS 1.3（199）、Android 1.3（166）以及 Docker Web 双架构镜像。

## 更新内容

- Bot 模式预载会话最近 50 条消息，切换时直接显示缓存；消息、运行、任务、授权和交付事件通过可续接的 SSE 增量同步，避免反复请求整个会话详情。
- 桌面/Web 的 Bot 列表默认挂载最近 120 条消息；显式展开历史时保留阅读位置，用户上滑与内容增长分别处理。
- iOS Bot 消息页直接移植 OpenMausBot 的 Markdown、气泡、表格与差异卡片，改用原生 ScrollView/VStack，并将历史分页改为按钮触发。点击入口直接导航，数据准备移到目标页，保留顶部头像入场和原生返回手势。
- iOS 构建号按已使用的 198 递增为 199。源码为 yaoyao-mobile `d7c0556`。
- Android 合并 Bot 缓存、账号隔离事件流、稳定消息 ID、正文缓存和底部跟随优化。源码为 yaoyao-android `f174fae`。
- Bot 未读状态改为持久化红点，跨客户端同步，不改变普通聊天的通知/推送计数。
- 快照与历史请求会合并请求期间的更新，避免旧响应恢复已删除消息或覆盖新文字。普通聊天与 Hermes Bot 的渲染和协议保持各自边界。

- `Yaoyao-1.3-166-android.apk`：Android 12 及以上，正式签名 APK。
- `Yaoyao-0.4.13-source.tar.gz`：Web/桌面源码与 Docker Compose 配置。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.13-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.13` | `linux/amd64` / `linux/arm64` |
| `samienluo/yaoyao:latest` | 固定版本验证后指向同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.13
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

使用 Compose 时设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.13`。现有标准/兼容桌面镜像不变，Cursor 继续使用 `samienluo/yaoyao-desktop:v0.4.12-cursor-amd`；不要删除工作区卷。所有旧标签与旧发布附件保留。

升级前备份数据及密钥。平台摘要、镜像运行验证和构建结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.13)，部署方法见 [Docker 文档](../docker-install.md)。模拟器滚动时长不等于真机帧率，本次不承诺未经实测的 FPS 数值。
