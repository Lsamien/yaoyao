# 夭夭 AI v0.4.72

本次发布 Web、macOS Apple Silicon 正式桌面版、Windows x64 未签名测试客户端和 Docker 双架构镜像，不提供 APK。

## 更新内容

- 修复 Bot 初始化时缺少环境快照引起的状态异常；可自动恢复并继续显示已有会话内容。
- 桌面端检测本机服务时延迟启动后台任务和虚拟机，正式进入本机模式后才启用；启用状态持久保存，重启和更新失败后的恢复更可靠。
- 修复已登录管理员跳过密码登录后电脑未重新注册的问题，进入远程模式时恢复设备授权。
- 电脑连接轮询与桌面登录使用一致的网络通道，改善局域网服务器的连接稳定性。
- 完善模式切换与退出流程中的设备连接和后台服务恢复。

## 升级说明

- 升级前备份完整 `.yaoyao` 数据目录，建议先更新服务端，再更新桌面客户端。
- macOS 桌面使用 Developer ID Application 正式分发签名及 Apple 公证，提供完整自动更新附件；已安装正式签名版的用户可使用“下载更新 → 重启更新”，历史开发签名版请先手动安装正式 DMG。
- Windows 为未签名测试客户端，可能提示未知发布者；安装到当前用户目录，连接已有服务器，不托管本机服务。
- Windows 测试更新清单随独立元数据压缩包提供，不写入正式自动更新源。Windows Server CI 验证结果与尚未完成的 Windows 10/11 真机项目分别列出，详见 [客户端说明](https://github.com/Lsamien/yaoyao/blob/v0.4.72/docs/windows-client.md)。
- 本次不构建、不上传 APK，旧版本标签和附件继续保留。
- 主项目采用 Apache-2.0，第三方组件保留各自许可与署名。

## Docker Hub

| 镜像 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.72-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.72` | `linux/amd64`、`linux/arm64` |
| `samienluo/yaoyao:latest` | 验证后更新为同一通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.72
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

Compose 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.72`。镜像发布到 Docker Hub，GitHub 提供安装及更新附件、源码和校验文件。

附件摘要、镜像摘要与实际验证结果见 [GitHub 发布页](https://github.com/Lsamien/yaoyao/releases/tag/v0.4.72)。
