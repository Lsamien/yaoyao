# 夭夭 AI v0.5.3

- 子账号开通后自动使用服务的 Hermes Profile。管理员创建账号或审核注册时直接开通，旧的按账号分配 Profile 设置停止生效。Android 同步更新了注册提示。
- 支持虚拟机的部署按账号授权。管理员可使用虚拟机，子账号默认关闭；撤销许可会停止该账号的虚拟机。同一账号的 Bot 共享一台虚拟机和工作目录，每个 Bot 有独立桌面和浏览器资料。
- Docker 部署取消固定桌面，不支持虚拟机。使用旧版独立虚拟机的部署，升级前请备份工作目录和浏览器资料；旧文件按 Bot 迁移到 `migrated/` 下。
- 提供 Web 源码、macOS Apple Silicon 客户端及更新文件、Android 1.5.0（231）和 SHA-256 校验文件。[下载附件](https://github.com/Lsamien/yaoyao/releases/tag/v0.5.3)
- Docker 镜像 `samienluo/yaoyao:v0.5.3` 和 `latest` 支持 AMD64 与 ARM64，`v0.5.3-amd` 供 AMD64 使用。备份应用数据后，按现有 Compose 配置拉取镜像并重新创建容器。
