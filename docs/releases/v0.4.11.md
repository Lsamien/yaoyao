# 夭夭 AI v0.4.11

本次发布 Web、macOS Apple Silicon 桌面版、Android 1.3（165）及 Docker Hub 双架构镜像，包含此前尚未正式发布的 v0.4.10 改动。

## 更新内容

- 优化会话侧栏、任务选择与新建任务入口，修复桌面 Bot 列表滚动。
- 修复从会话菜单打开聊天设置时可能编辑错误会话的问题，按实际菜单目标打开并保存。
- 机器人在不同单聊、群聊中的忙碌、等待和排队状态统一展示；安卓同步更新这些状态。
- 模型 Worker 自动继承基础 Hermes Profile 的代理配置，显式设置的执行环境代理保持优先。
- 任务进度与输入框等宽对齐，并缩小两者间距。

## 下载

## Docker Hub 远程镜像

镜像仓库：[samienluo/yaoyao](https://hub.docker.com/r/samienluo/yaoyao)。

| 镜像标签 | 架构 |
| --- | --- |
| `samienluo/yaoyao:v0.4.11-amd` | `linux/amd64` |
| `samienluo/yaoyao:v0.4.11` | 自动匹配 `linux/amd64` / `linux/arm64` |
| `samienluo/yaoyao:latest` | 本次发布后指向已验证的 `v0.4.11` 通用镜像 |

```sh
docker pull samienluo/yaoyao:v0.4.11
# 固定使用 AMD64：
docker pull samienluo/yaoyao:v0.4.11-amd
```

在 `docker.env` 中设置 `HERMES_YAOYAO_IMAGE=samienluo/yaoyao:v0.4.11` 或 `samienluo/yaoyao:latest` 后更新：

```sh
docker compose --env-file docker.env pull web
docker compose --env-file docker.env up -d --no-build web
```

镜像的实际 digest、架构与运行核验结果记录在本版本 GitHub 发布页。固定版本验证通过后更新 `latest`，所有旧版本标签保留。

## 升级

官方发布地址为 https://github.com/Lsamien/yaoyao/releases/tag/v0.4.11 。App 首次启动继续只同步较旧的本机 Web，保留已有更新的独立 Web；默认数据目录为 `~/.yaoyao`。

升级前备份完整数据目录及加密密钥。源码部署重新构建，Docker 部署拉取已发布镜像并重建容器，保留原数据目录和命名卷。
