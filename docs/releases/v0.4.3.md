# v0.4.3

本次同时更新 Web 与 macOS Apple Silicon（arm64）桌面版。

- 统一聊天归档、永久删除和退群后的数据处理，避免遗留会话与关联状态不一致。
- 修复更新面板的检查/升级状态展示，明确区分“待检查”、失败和可升级状态。
- 改进聊天列表操作提示的可见性，归档聊天与搜索列表的操作反馈更清晰。

## 安装与升级

GitHub 发布附件提供 `Yaoyao-0.4.3-arm64.dmg` 和 `SHA256SUMS.txt`。桌面包使用 Apple Development 开发签名，未做 Apple 公证，仅适用于 macOS Apple Silicon。

可从 App 的“检查 App 更新…”下载、校验后手动安装，或将 DMG 中的“夭夭”拖入“应用程序”。App 首次启动仅向上同步较旧的本机 Web；已有较新的服务保留。

Web 通过 GitHub Release 检查更新。源码部署切换到 `v0.4.3` 后重新构建并重启；Docker 部署重新构建镜像。升级前备份完整 Web 数据目录。详情见 [GitHub 版本升级](../github-updates.md)。
