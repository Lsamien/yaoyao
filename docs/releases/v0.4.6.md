# 夭夭 AI v0.4.6

本次更新 Web 与 macOS Apple Silicon 桌面版，新增 Bot 插件与工具入口，并修复群聊重复确认无法自动收尾的问题。附带的 Android 1.3（162）APK 与上一版本一致。

## 更新内容

- Bot 模式侧栏新增“工具”：插件、自动化、已连接应用；账号菜单提供设置、关于和帮助，帮助链接指向 https://yaoyao.samien.cn 。普通聊天模式保持原有入口。
- 设置中新增 Composio 应用连接和自定义 MCP 服务。MCP 支持 stdio 与 Streamable HTTP，可测试、启用、停用、编辑、移除并选择授权 Bot；应用连接支持账号别名、逐账号断开和 Bot 授权。
- 插件凭据按账号加密保存且不回显，工具仅挂载到获准 Bot 的当前执行；插件停用或权限变化后拒绝旧调用。自定义 MCP 由管理员配置和使用，应用连接需配置自己的 Composio API Key。
- 自动化入口复用现有 Bot 定时任务，支持选择机器人、创建任务、立即执行和查看运行日志。
- 群聊过滤“收到、感谢、审核通过、等待用户指令”等确认性提及，避免重复派工。管理员协调与自由协作均增加持久化重复分支保护，保留正常复核、新结果和不限轮数协作。
- 修复后端恢复时的重复派工风险；触发保护时保留原回复，只停止重复分支，其他工作继续完成。

## 升级与使用

官方发布地址为 https://github.com/Lsamien/yaoyao/releases/tag/v0.4.6 。App 首次启动继续只同步较旧的本机 Web，保留已有更新的独立 Web；数据目录仍为 `~/.yaoyao`。

插件功能仅用于 Bot 模式，不修改普通 Hermes 聊天的工具配置。对应 Bot 执行环境需要支持现有原生工具桥。应用连接的授权流程需要有效的 Composio 项目配置；本次相关第三方流程通过模拟服务验收，没有预置生产密钥。

升级前备份完整数据目录及加密密钥。源码或 Docker 部署更新版本后重新构建并重启服务，保留原数据目录或命名卷。
