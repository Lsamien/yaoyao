# v0.3.15

Web 与配套 iOS 1.3（176）的内置头像完整采用 OpenMausBot 的轮廓、纯色、五官、表情和状态动画。Logo 与聊天页面布局保持现状。

- 设置提供 11 种颜色、8 种基础外形、10 种额外造型、10 种基础表情。选择基础外形会清除额外造型。
- 上传照片支持圆形、圆角方形和方形裁剪，保存裁剪方式，不修改图片原始数据。
- 旧内置头像一次性归一为绿色 `#00C875`、圆形、默认表情；旧照片保留，默认圆角。已保存的 v2 设置不会再次重置。基础 Agent 元数据通过现有 Profile 读取与保存接口归一化。
- 群头像继续根据实际成员资料合成；执行、排队、待确认与完成／失败／新消息状态驱动对应头像动画。
- 小尺寸空闲列表头像静止；活动头像、聊天头部与设置预览支持动态。Web 支持指针跟随。离屏、后台和减少动态效果时暂停。
- 新增版本化头像描述，沿用原保存接口、图片存储、鉴权和大小限制。

来源、许可与移植说明见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。验证方法见 [头像验收记录](../verification/avatar-v2.md)。
