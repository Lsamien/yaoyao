# 管理后台

管理与系统设置只在独立的管理后台完成。后台与夭夭 Web 在同一个服务进程中运行，但使用单独的端口、登录和会话，只允许管理员账号登录。夭夭 Web（15300）不再提供任何管理接口或管理界面。

## 打开后台

| 部署方式 | 地址 |
| --- | --- |
| npm / 源码 | 服务器本机 `http://127.0.0.1:15301`；`yaoyao admin` 显示地址 |
| Docker | 宿主机 `http://127.0.0.1:15301`（只发布在宿主机回环地址） |
| macOS 完整版 | 菜单「夭夭 → 打开管理后台…」，或「我的设置 → 管理后台」中的按钮；端口为 Web 端口 + 1 |
| 其他电脑 | SSH 隧道：`ssh -L 15301:127.0.0.1:15301 服务器`，再在本机打开 `http://127.0.0.1:15301` |

首次使用前需要已有管理员账号（在夭夭 Web 首次打开时创建）。使用 App 内置服务且从未设置过密码的管理员，先在夭夭「我的设置 → 登录与安全」设置密码。

## 功能

| 页面 | 内容 |
| --- | --- |
| 概览 | 内置 Hermes、账号、电脑与执行节点在线情况，待处理事项，最近操作 |
| 用户与权限 | 新建、停用、删除账号，审核注册，分配基础机器人 |
| 模型服务 | 供应商与默认模型、订阅账号登录、API Key 与工具密钥、辅助模型 |
| 执行与权限 | 执行位置与授权、命令审批策略、服务器本机工具、文件访问范围 |
| 记忆服务 | OpenViking 连接与会话同步 |
| 电脑与设备 | 生成电脑配对码、远程电脑、设备授权、执行节点、Grok 云电脑授权 |
| 本地虚拟机 | 镜像、实例与空闲策略 |
| 消息推送 | APNs 与 FCM |
| 语音 | 双流语音、语音合成与识别服务商 |
| 网络与安全 | 服务器名称、外网访问地址、后台访问方式 |
| 更新与回滚 | 检查、更新、回滚 |
| 审计日志 | 登录与所有修改记录，筛选与导出 CSV |
| 我的账号 | 修改密码、二次验证 |

## 安全设计

- **只允许管理员**：普通账号输入正确密码也会被拒绝，并记入审计日志。
- **会话隔离**：后台会话保存在 `admin-sessions.json`，Cookie 名为 `yaoyao_admin_session`（HTTPS 下为 `__Host-yaoyao_admin_session`），有独立的 CSRF 令牌。浏览器的 Cookie 不按端口区分，所以后台既不读取、也不写入 Web 的会话和 CSRF Cookie；Web 的会话在后台无效，后台会话在 Web 无效。
- **会话时长**：空闲 30 分钟或登录 8 小时后失效，没有“记住我”。修改密码会让这个管理员在 Web 和后台的所有登录失效。
- **登录限流**：同一来源地址或同一账号 10 分钟内失败 5 次，锁定 15 分钟。
- **再次确认密码**：修改 API Key 与模型服务、推送证书、更新与回滚、外网访问地址、删除账号、注册执行节点、生成电脑配对码等操作，需要在 10 分钟内输入过密码（登录时自动计入）。超时后接口返回 `428 admin_reauth_required`，在顶栏点「确认密码」即可。
- **二次验证**：验证器 App 的 6 位验证码（TOTP），绑定时提供 10 个一次性恢复码。本机访问时可选；后台允许远程访问时必须开启，首次登录后只能先完成绑定。
- **审计日志**：所有登录尝试和写操作都会记录时间、账号、来源地址、模块、操作、结果和摘要；密钥类字段只记“已修改”。保存在 `admin-audit.sqlite`，保留 180 天。

## 远程访问

默认只监听 `127.0.0.1`。确需从其他机器直接访问时：

```sh
YAOYAO_ADMIN_HOST=0.0.0.0
YAOYAO_ADMIN_ALLOW_IPS=10.0.0.5,192.168.1.0/24   # 必填：允许的来源 IP 或网段
HERMES_YAOYAO_TLS_CERT=/path/cert.pem            # 必填：与 Web 共用证书
HERMES_YAOYAO_TLS_KEY=/path/key.pem
```

缺少白名单或证书时服务拒绝启动。`YAOYAO_ADMIN_INSECURE_HTTP=1` 只用于端口仅发布在宿主机回环地址的场景（Docker 默认配置即如此）。`YAOYAO_ADMIN_PORT` 可改端口，`YAOYAO_ADMIN_PORT=off` 关闭后台。

## 注册电脑

在后台「电脑与设备」生成配对码（10 分钟内有效，只能使用一次），然后在要加入的电脑上打开夭夭 App，以客户端模式登录服务器，在「我的设置 → 运行模式」或菜单「电脑 → 用配对码注册这台电脑…」输入配对码。电脑不再需要管理员在 App 中登录。

## 对客户端的影响

- **夭夭 Web**：设置中心只保留个人设置与 Bot 自身设置，「管理后台」入口说明如何打开后台。旧的管理接口返回 `410 moved_to_admin_console`。
- **iOS / Android**：服务器返回能力 `admin-console-v1` 时，服务器名称、Grok 云授权、环境与授权变为只读并提示到后台操作。
- **接口**：后台沿用原来的管理接口路径（`/api/app/admin/*`、`/api/app/system/*` 等），只在后台端口提供；后台自身的登录、会话、二次验证和审计接口在 `/api/app/console/*`。
